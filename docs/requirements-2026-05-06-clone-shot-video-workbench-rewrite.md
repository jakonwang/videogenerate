# 2026-05-06 `/clone` 第 4 阶段分镜视频工作区重写

## 背景

`/clone` 第 4 阶段“分镜视频生成”连续多轮按卡片样式微调后，仍然存在以下问题：

- 排版像素材卡片墙，不像专业视频工作台
- 视频卡高度不一致，页面被内容撑长
- 信息层级混乱，失败恢复与单镜重试不直观
- 用户需要滚动很长距离才能定位某个镜头

本轮不改 IPC 和后端生成语义，只重写第 4 阶段前端工作区结构。

## 目标

把第 4 阶段从“多卡片平铺展示”改成更接近剪辑软件 / 检查器式的三栏工作区：

1. 左栏：镜头队列
2. 中栏：当前镜头预览监视器
3. 右栏：运行检查器与单镜控制

核心原则：

- 一次只聚焦一个镜头
- 主操作保持唯一，阶段主按钮仍在统一头部
- 镜头级动作收敛到右侧检查器
- 高度受控，滚动限定在工作区内部

## 修改范围

- `src/renderer/src/ui/views/CloneView.vue`

## 实现内容

### 1. 新增镜头选中态

- 新增本地状态：`selectedShotId`
- 新增计算状态：`selectedShotOutput`
- 当镜头列表变化时，自动回落到首个可用镜头，避免空白态

### 2. 第 4 阶段模板重写

原结构：

- 顶部摘要卡
- 中部多张视频结果卡并列展示

新结构：

- `shot-workbench`
  - `shot-list-panel`
  - `shot-preview-panel`
  - `shot-inspector-panel`

### 3. 镜头队列

每个镜头项显示：

- 镜头序号
- 镜头标题
- 分镜脚本摘要
- provider / model
- 当前状态
- 时长
- ready / error / pending 点状状态

点击镜头项即可切换中央预览和右侧检查器。

### 4. 中央预览监视器

中央区域固定展示当前选中镜头：

- 上一镜 / 下一镜切换
- 大尺寸视频预览
- 当前分镜脚本卡
- 当前镜头状态 badge
- 时长 / 远端状态 / provider / model
- taskId / source / capability

如果当前镜头还没有视频，展示明确的待结果状态，不再把空卡片平铺在列表里。

### 5. 右侧检查器

右侧统一展示当前镜头的：

- 当前镜头摘要
- 状态判断
- 运行摘要
- 错误信息
- 单镜操作

保留并强调已有能力：

- 继续查询当前镜头结果
- 重新生成当前镜头
- 同步全部云端状态

### 6. 布局与滚动策略

- 桌面端：三栏固定工作区
- 中屏：左栏 + 中栏，上方保留，右侧检查器下沉为整行
- 小屏：三栏纵向堆叠
- 滚动只发生在：
  - 镜头队列内部
  - 检查器内部
- 中央预览区高度固定，不再因视频列表数量撑高整个页面

## 不变项

- 不改 `window.api.clone.generateShotVideosFromStoryboard`
- 不改 `window.api.clone.syncShotVideoTask`
- 不改 `window.api.clone.generateShotClip`
- 不改第 4 阶段业务语义

## 使用说明

进入 `/clone` 第 4 阶段后：

1. 左侧点选需要查看的镜头
2. 中间直接查看该镜头预览结果
3. 右侧执行继续查询或重新生成
4. 阶段级主按钮仍用于继续生成剩余镜头

## 2026-05-06 Refine Pass 2

本轮继续收紧第 4 阶段界面，目标是不再让页面像素材卡片墙，而是更接近专业剪辑软件的镜头检查工作台。

### 最新结构

- 左侧主区改为表格化 `Shot List`
- 每行只表达一个镜头：
  - 镜头编号
  - 缩略图
  - 分镜脚本摘要
  - 时长
  - Provider / Model
  - 状态
  - 行内轻操作
- 右侧固定为两段：
  - 当前镜头预览
  - 运行反馈 Console

### 本轮收掉的旧结构

- 移除底部横向 timeline strip
- 移除预览区重复 metrics 卡片
- 移除旧的中区/下区多块并排检查器布局
- 把单镜操作统一收进右侧 Console，不在主列表区堆多个主按钮

### 使用说明更新

进入 `/clone` 第 4 阶段后：

1. 先在左侧分镜列表里选中镜头
2. 在右侧预览当前镜头视频和脚本
3. 在右侧 Console 执行查询结果或重新生成
4. 顶部唯一主按钮仍用于继续生成剩余镜头
