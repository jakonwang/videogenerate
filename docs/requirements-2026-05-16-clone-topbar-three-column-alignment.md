# 2026-05-16 Clone 顶栏流程带三段式对齐

## 目标

- 将 `/clone/[projectId]` 顶栏按设计稿收敛为单条三段式结构。
- 只处理复刻详情页顶栏，不扩散到其他工作台页面。

## 结构要求

- 左：流程导航
- 中：空白过渡
- 右：GPU / API / 账号状态

## 本轮最小改动

- 修改文件：
  - `src/renderer/src/ui/MainLayout.vue`

- 具体调整：
  - 仅在 clone 详情页场景下启用新的顶栏结构。
  - 将原“普通头部 + 下方流程带”合并为单条顶栏。
  - 保留步骤点击交互，继续通过既有 `cloneTopbar` store 分发阶段切换。
  - 为新顶栏补充独立样式：
    - 左侧步骤流
    - 中间留白
    - 右侧状态分栏
  - 非 clone 页面仍保留原顶栏，不做共性重构。

## 结果

- 复刻详情页顶栏更贴近用户设计稿的结构意图。
- 首屏视觉重心更集中在流程带本身。
- 保持现有阶段切换能力不变。

## 使用说明

1. 进入桌面端 `/clone/[projectId]`。
2. 查看页面顶部单条流程带。
3. 点击左侧流程步骤，确认仍可切换阶段。
4. 观察右侧状态分栏是否按 GPU / API / 账号状态展示。

## 验证

- Windows 开发环境执行：
  - `npm run typecheck`
