# 2026-05-06 首页高清参考图对齐精修

## 背景

基于用户提供的首页超高清参考图，对现有 `/home` 首页工作台进行一轮高保真精修。

本次目标不是新增业务功能，而是在保持现有前后端分离和数据链路不变的前提下，使首页视觉结构、信息密度和右侧辅助区更接近参考稿。

## 修改范围

- `src/renderer/src/ui/views/HomeView.vue`
- `src/renderer/src/ui/MainLayout.vue`
- `docs/requirements.md`

## 实现内容

### 1. 首页 Hero 区重做

- 调整主标题、描述和双按钮布局
- 重绘 AI 核心视觉区，强化紫蓝发光立方体和轨道标签
- 增加浮动标签按钮，提升首屏“AI 生产工作台”感知

### 2. KPI 卡片精修

- 将 5 个指标卡统一为更紧凑的暗色玻璃面板
- 调整图标底板、数字字号、底部趋势高光
- 让首页首屏的数据密度更接近参考稿

### 3. 任务表格对齐

- 任务区改为更接近控制台式表格结构
- 增加操作列按钮
- 统一任务缩略块、进度条、步骤文案和时间列层次

### 4. 流程可视化精修

- 保留现有工作流节点逻辑
- 统一节点高度、间距和运行中高亮样式
- 与首页任务区形成并列双栏关系

### 5. 推荐模板区升级

- 增加模板分类 tabs
- 模板卡片改为更接近参考稿的横向推荐样式
- 保持模板数据来源不变

### 6. 右侧辅助区补齐

- 快速创建区按参考稿压缩为高密度入口卡
- 新增 AI 助手卡片，包含欢迎文案、建议问题和输入框
- 通知区继续保留系统动态入口

### 7. 主壳层细节调整

- 微调顶部搜索框宽度、状态 chip、用户区尺寸
- 细调侧栏品牌图标质感
- 保持主布局结构不变，不改路由和业务逻辑

## 不做的内容

- 不修改 `window.api.*` 现有接口
- 不改任务、模板、通知的数据来源
- 不引入新的后端能力
- 不把设计稿 HTML 直接贴入生产代码

## 使用说明

### 开发预览

Windows 开发环境运行：

```bash
npm run dev
```

进入首页 `/home` 即可查看新版效果。

### 验证

Windows 开发环境执行：

```bash
npm run typecheck
```

## 验收标准

1. 首页整体层次、信息密度和右侧辅助区明显更接近高清参考图
2. 首页 Hero、KPI、任务表、流程卡、模板区和右侧栏视觉风格统一
3. 不破坏现有导航、任务读取和模板读取逻辑
4. 中小屏下布局仍可正常收缩
5. `npm run typecheck` 通过
