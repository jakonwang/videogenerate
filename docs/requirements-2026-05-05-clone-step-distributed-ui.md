# /clone 按步骤分布式 UI 收敛

## 摘要

本次仅调整 `/clone` 前端展示层，不改后端主流程、任务状态机和供应商透传链路。

目标：

- 不再把参考视频、脚本、分镜、视频、合成全部堆在一个页面同时渲染
- 改为按步骤分布式展示
- 保留右侧全局状态、日志、历史记录
- 避免页面卡顿和信息过载

## 变更要求

- 顶部步骤条改为可点击切换的步骤入口
- 主工作区只渲染当前步骤对应内容：
  - 分析参考视频
  - 脚本变体评分
  - 分镜生成
  - 分镜视频生成
  - 合成最终成片
- 右侧栏持续显示：
  - 当前步骤摘要
  - 运行反馈
  - 历史记录
- 不允许在 `/clone` 页面内部重复绘制应用级左侧导航

## 文案调整

- “分镜拼图”在页面语义上收敛为“分镜生成”
- “生成拼图”按钮文案收敛为“生成分镜”
- 视频失败恢复入口保留：
  - 继续查询结果
  - 重试该分镜
  - 同步状态

## 2026-05-05 晚间补充

- 顶部步骤条进一步收敛为低高度工作台标签，不再使用高卡片说明文案
- 移除重复的 Hero 区和“当前步骤”摘要块，减少同屏重复信息
- 主工作区、右侧状态栏、历史记录统一缩小圆角、字体、间距、卡片高度
- 分镜阶段保留逐帧状态与九宫格结果，但不再强化“大拼图展示感”
- 目标风格调整为更紧凑、更轻量、更接近剪映式三栏工作台，而不是大块表单页

## 2026-05-05 顶部工作流头部重做

- `/clone` 顶部工作流头部重新按设计稿语义收敛为三段：
  - 顶部标题区：面包屑、主标题、状态 badge、详情编辑入口
  - 中部步骤轨道：5 步圆点连线，可点击切换查看步骤，当前步骤高亮发光
  - 底部摘要条：当前步骤说明、整体进度、已用时间、预计剩余、详情入口
- 顶部操作按钮统一为同一高度与圆角体系，避免窗口缩小时按钮变形或挤压错位
- 新增自适应规则：
  - `> 1400px` 保持完整横向头部布局
  - `1180px - 1400px` 收紧按钮与步骤间距
  - `860px - 1180px` 步骤轨道改为横向滚动，摘要条改为两列
  - `< 860px` 按钮纵向堆叠，摘要条单列，避免头部炸裂
- 本次仅调整 `/clone` 前端展示层，不改变五阶段主流程、任务状态机、模型透传与后端任务恢复链路


## 2026-05-05 语言识别修正

- `/clone` 创建参考视频 blueprint 时，不再前端强制传入 `zh-CN`
- 后端参考视频分析默认不再把未指定 locale 的视频统一压成中文链路
- 分析页右侧“标题/市场/语言/节奏”改为更紧凑的 inspection panel 风格
- 脚本变体列表改为更扁平的 worklist 风格，减少大黑框与无效留白

## 验收标准

1. `/clone` 页面默认只展示当前步骤内容
2. 点击顶部步骤条可以切换查看其他步骤
3. 页面内不再出现重复左侧菜单
4. 页面刷新后仍能按当前项目状态继续查看和推进
5. `npm run typecheck` 通过
