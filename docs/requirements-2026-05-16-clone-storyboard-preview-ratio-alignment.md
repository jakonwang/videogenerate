# 2026-05-16 Clone 分镜设计布局与比例对齐

## 目标

- 将 `/clone/[projectId]` 的“分镜设计”阶段改为更接近设计稿的双栏结构。
- 修正分镜缩略图与预览图的显示比例，避免 9:16 图片被压成 1:1。

## 本轮最小改动

- 修改文件：
  - `src/renderer/src/ui/views/CloneView.vue`

- 具体调整：
  - 将分镜设计阶段主工作区调整为：
    - 左侧分镜列表
    - 右侧分镜预览
  - 右侧预览区展示：
    - 当前选中镜头预览图
    - 镜头文案
    - 时长 / 景别 / 运镜
    - 脚本内容
  - 新增 grid 阶段专用的 `selectedStoryboardRow / selectedStoryboardFrame / selectedStoryboardBeat` 计算，避免复用视频阶段选中态。
  - 列表缩略图与右侧预览图统一改为 9:16 容器，并使用 `object-fit: contain` 保留真实比例。

## 结果

- 分镜设计阶段更接近用户设计稿的左右结构。
- 竖版分镜图按真实比例显示，不再被裁成方图视觉。
- 当前镜头的预览与脚本查看更清晰。

## 使用说明

1. 进入桌面端 `/clone/[projectId]`。
2. 切换到“分镜设计”阶段。
3. 左侧点击任一镜头行。
4. 右侧应同步显示该镜头预览图与脚本信息。
5. 若图片本身是 9:16，应以竖版比例显示。
