# 2026-05-11 Web-Next 脚本生成页设计稿对齐

## 背景

- 当前 `apps/web-next/app/clone/[projectId]/page.tsx` 的第二阶段虽然已是脚本工作区，但和最新暗色设计稿仍有差距。
- 设计稿强调的是：
  - 左栏参考视频与分析完成状态
  - 中栏脚本版本列表与大号评分
  - 右栏脚本生成设置
- 本轮继续只处理 `apps/web-next`，不改后端 API 协议。

## 目标

- 将 `generate_script_variants` 阶段精修为更贴近设计稿的三栏桌面端工作台：
  - 左栏：参考视频卡 + 分析完成提示
  - 中栏：脚本变体列表
  - 右栏：脚本生成设置
- 保留现有脚本相关能力：
  - 生成脚本候选
  - 选择主版本
  - 修改生成数量
  - 上一步 / 下一步
- 脚本阶段同样隐藏外层共享运行侧栏，避免设计稿三栏结构被挤窄。

## 实现说明

- 修改文件：
  - `apps/web-next/app/clone/[projectId]/page.tsx`
- 本轮实现内容：
  - 第二阶段标题改为“脚本生成”
  - 顶部动作改为“保存项目 / 下一步：分镜设计”
  - 左栏新增：
    - 参考视频预览
    - 分析完成提示卡
  - 中栏重做脚本版本列表：
    - 版本编号
    - 推荐标识
    - 大号综合评分
    - 候选脚本摘要
    - 生成更多脚本入口
  - 右栏重做脚本生成设置：
    - 脚本风格
    - 时长
    - 语言
    - 生成数量
    - 当前模特信息
    - 上一步 / 下一步
  - 脚本阶段切换为单主栏外层布局，隐藏共享 `RuntimeSidebar`

## 边界

- 不修改后端脚本生成协议与数据结构。
- 不扩展新的脚本设置接口。
- 不改动其他阶段的业务链路。
- Windows 本地开发与 Linux 部署保持兼容。

## 使用说明

- 本地验证命令：
  - `npm run typecheck:web-next`
  - `npm run build:web-next`
- 页面验收重点：
  - 第二阶段是否已为三栏脚本工作台
  - 外层共享右栏是否在脚本阶段隐藏
  - 脚本版本评分区是否明显更接近设计稿
  - 右侧生成设置区是否独立且密度更高
