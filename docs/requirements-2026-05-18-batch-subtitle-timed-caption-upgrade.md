# 2026-05-18 视频批量加字幕升级为时间轴字幕

## 目标

- 将原本“静态标题贴片”能力升级为更接近剪辑软件的“手工时间轴字幕”能力。
- 让批量字幕的预览和最终导出走同一套 ASS/libass 渲染链，避免预览和成片不一致。

## 本轮最小改动

- 保持改动集中在批量字幕模块，不扩散到其他页面或全局架构。
- 继续兼容旧的静态标题贴片模式，同时新增 `timed_caption` 与 `hybrid` 模式。
- 在现有工作台内补上字幕轨编辑、重排、真实预览与批量导出闭环。

## 实现内容

- 后端新增批量字幕任务增强字段：
  - `subtitleMode`
  - `captionStyle`
  - `layoutPolicy`
  - `subtitleTracks`
- 新增接口：
  - `POST /plugins/video-batch-subtitle/jobs/:id/reflow`
- 字幕轨链路：
  - 手工录入逐句时间轴
  - 根据当前字幕样式与排版策略进行自动断句与换行
- 统一渲染链：
  - 预览不再使用前端经验缩放修正
  - 预览与导出统一改为 FFmpeg + ASS/libass
  - 字体、位置、描边、阴影和换行规则统一
- 前端工作台升级：
  - 增加 `时间轴字幕 / 静态标题 / 标题+字幕` 模式切换
  - 增加“重新断句”
  - 增加字幕轨文本编辑区
  - 中部预览改为真实渲染短视频

## 使用说明

1. 进入 `插件 -> 视频批量加字幕`
2. 选择本地视频或成片库视频
3. 在字幕轨编辑区按 `开始秒<TAB>结束秒<TAB>文本` 形式录入时间轴字幕
4. 在右侧样式区调整字体、字号、描边、宽度比例、底部边距
5. 点击“重新断句”按当前样式重排字幕
6. 在中部真实预览区确认效果
7. 点击“批量渲染”输出新成片

## 兼容说明

- 旧任务仍可继续读取与导出。
- 旧静态贴片逻辑未删除，仍可切换到 `static_title`。
- Windows 开发与 Linux 部署继续复用现有字体回退与 FFmpeg 能力。

## 验证方式

- `npm run typecheck`
- `npm run build`

## 人工验收重点

- 对同一条视频，预览和导出在同一时间点字幕文案、位置、换行保持一致。
- 无音频视频不影响手工时间轴字幕录入；若素材本身损坏导致无法预览或导出，应给出明确失败原因，不进入伪成功状态。
- 调整最大行数和宽度比例后，重新断句结果会变化，且导出结果与预览一致。
