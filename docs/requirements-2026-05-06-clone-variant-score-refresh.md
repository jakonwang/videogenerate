# 2026-05-06 `/clone` 脚本变体评分界面高清稿对齐

## 背景

用户提供了 `/clone` 第二阶段“脚本生成 / 脚本变体评分”高清参考图，要求将当前脚本变体评分界面按设计稿精修。

本次只处理 `visibleStageKey === 'variant'` 的前端展示层，不改脚本生成链路、不改变体数据结构、不改后端调用。

## 修改范围

- `src/renderer/src/ui/views/CloneView.vue`
- `docs/requirements.md`

## 实现内容

### 1. 第二阶段头部对齐

- 保留顶部六阶段工作流与“保存项目 / 下一步”操作区
- 维持现有步骤切换逻辑
- 微调第二阶段在轨道中的激活表现

### 2. 左侧参数配置区精修

- 保留脚本模式 tabs：智能生成 / 自定义主题 / 导入文案
- 优化“脚本生成方向”文本区层级和字号
- 调整高级选项列表密度与“更多设置”样式
- 保留 AI 灵感推荐模块并提高可读性

### 3. 中间脚本版本卡重做

- 脚本版本区按参考稿改为更突出版本卡
- 综合评分圆环加入主分数 + 文案结构
- 评分条展示更接近参考稿布局
- 操作区统一为预览 / 应用 / 收藏

### 4. 右侧分析栏精修

- AI 脚本分析卡增加双层雷达视觉

- 热门脚本结构参考卡加入图标底板和更接近稿件的按钮布局

## 不做的内容

- 不改脚本生成接口
- 不改变体评分算法

## 使用说明

Windows 开发环境运行：

```bash
npm run dev
```

进入 `/clone` 后切到第二阶段“脚本生成”查看效果。

验证命令：

```bash
npm run typecheck
```

## 验收标准

1. 第二阶段整体结构更接近参考稿：左配置、中间脚本版本卡、右分析栏
2. 评分圆环、评分条、版本卡层次更清晰
3. 不影响脚本版本生成和应用逻辑
