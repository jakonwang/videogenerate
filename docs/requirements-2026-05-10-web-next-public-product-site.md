# 2026-05-10 Web-Next 公开产品站与客户端下载引导

## 背景

本轮目标不是继续把“融资感产品介绍”塞进工作台首页，而是为 `apps/web-next` 增加一层独立的公开产品站，用于承担产品叙事、销售介绍、定价说明和客户端下载转化。

同时，针对依赖本机环境的模块，必须明确能力边界，避免用户误判为纯 Web 可直接执行。

## 实施范围

### 1. 路由分层

新增公开产品站：

- `/`
- `/product`
- `/pricing`
- `/download`

保留登录后工作台：

- `/login`
- `/clone`
- `/clone/[projectId]`
- `/templates`
- `/models`
- `/materials`
- `/live-clips`
- `/production`
- `/settings`
- `/billing`
- `/account`

说明：

- 公开站与工作台视觉 token 统一，但不共用 `AppShell`
- 工作台继续服务于任务执行与结果协同，不承担公开宣传叙事

### 2. 需客户端运行的模块提示

本轮明确以下模块需要桌面客户端支持：

- `直播切片`
- `生产中心`

实现方式：

- 左侧菜单加 `需客户端` 标签
- 对应页面顶部统一显示桌面客户端说明卡
- 卡片明确说明依赖：
  - 本机 GPU / 算力
  - 本地文件系统
  - 桌面客户端运行环境
- 页面提供：
  - `下载桌面客户端`
  - `查看安装说明`

约束：

- 不直接强跳下载页
- 不在 Web 页面中伪装“可以直接运行”
- Web 只承接配置、说明、状态查看和任务协同

### 3. 公开产品站页面

#### `/`

定位为公开入口首页，强调：

- 企业级 AI 视频生产平台
- 公开站与工作台分层
- 生产链路一屏讲清
- 桌面客户端与 Web 协同关系

#### `/product`

用于产品介绍和融资演示，覆盖：

- Hero
- 能力总览
- 工作流展示
- 商业价值
- 为什么需要桌面客户端

#### `/pricing`

用于公开定价展示，覆盖：

- 会员能力与算力包分层
- 基础版 / 专业版 / 团队版
- 算力包展示
- 客户决策辅助说明

技术说明：

- 前端复用 `listPlans()` 作为动态展示来源
- 接口不可用时回退为静态定价展示

#### `/download`

用于桌面客户端下载说明，覆盖：

- Windows 客户端优先
- 版本号与下载入口
- 安装步骤
- 客户端能力说明
- 历史版本预留结构

技术说明：

- 复用桌面端更新检查接口回退逻辑
- 优先读取最新版本信息
- 为空时展示空状态而不报错

### 4. Web API 补充

共享层新增：

- `DesktopReleaseItem`
- `DesktopReleaseInfo`
- `getDesktopLatestRelease()`
- `listDesktopReleases()`

实现原则：

- 不扩展新的后端协议
- 优先复用现有客户端更新接口
- 接口失败时前端优雅降级

### 5. 同步收口页面

本轮同步整理：

- `/login`
- `/billing`
- `/live-clips`

目标：

- 清理乱码与混杂文案
- 明确页面职责
- 保持公开站与工作台边界清晰

## 使用说明

### 本地开发

- Windows 环境开发与调试
- 命令：
  - `npm run dev:web-next`
  - `npm run build:web-next`

### 部署约束

- 生产部署环境为 Linux
- 实现中不得依赖 Windows 专属路径写法
- Web 页面只通过 API 与本地持久化协作，不将桌面端执行逻辑直接塞回页面层

## 验收点

- 未登录用户可访问 `/`、`/product`、`/pricing`、`/download`
- 工作台与公开站导航不互相污染
- `直播切片` 与 `生产中心` 菜单都显示 `需客户端`
- 两个模块页面都能看到固定说明卡与下载入口
- `/download` 至少能展示最新客户端信息或合理空状态
- `/pricing` 能展示静态套餐与动态接口回退
- `npm run build:web-next` 通过

## 2026-05-10 稳态与回退补充

- 本轮继续只处理 `apps/web-next`，不改后端 API 协议。
- 已补齐公开页与关键工作台页的稳定性分支：
  - `/pricing`
    - 动态套餐接口失败时显示明确错误提示与重试入口
    - 同时保留静态公开定价，不出现信息断层
  - `/download`
    - 远端版本读取失败时显示错误提示、重试入口和本地回退文案
    - 没有可读版本时显示明确空状态，而不是只给无效下载按钮
  - `/workspace`
    - 最近任务查询失败时显示错误状态
    - 没有任务时显示首任务引导，不再留空
  - `/clone`
    - 任务列表查询失败时显示错误状态和重试入口
    - 搜索或筛选结果为空时给出清空筛选入口
    - 无任务时给出首任务创建入口
- 鉴权体验补充：
  - 受保护页在会话恢复阶段显示“恢复中”提示，不再把“未就绪”和“需跳登录”混成一个空白过渡
- 本轮验证要求：
  - Windows 本地执行 `npm run typecheck:web-next`
  - Windows 本地执行 `npm run build:web-next`
