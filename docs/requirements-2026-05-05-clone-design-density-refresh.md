# `/clone` 页面设计密度收口说明（2026-05-05）

## 背景

用户持续反馈 `/clone` 页面存在以下问题：

- 字体过大，不精致
- 视频和图片预览过大，9:16 短视频工作区不紧凑
- 卡片过厚、留白过多，缺少专业工具感
- 缩放窗口后布局容易变乱
- 右侧运行反馈与历史区过于臃肿

本次调整以 `DESIGN.md` 为唯一视觉基线，只修改 `/clone` 前端展示层，不改后端链路和五阶段流程。

## 目标

将 `/clone` 页面收口为更克制、更高密度的专业工作台风格：

- 保留现有五阶段流程
- 保留现有按钮行为、IPC 调用、任务状态逻辑
- 压缩标题、卡片、按钮、预览尺寸
- 优化 9:16 视频与分镜图展示比例
- 加强中小窗口下的响应式稳定性

## 本次修改范围

文件：

- `src/renderer/src/ui/views/CloneView.vue`

修改内容：

- 调整 `/clone` 页面背景、容器、边框、玻璃质感，使其与 `DESIGN.md` 深色体系一致
- 收缩顶部标题区、步骤区、状态胶囊、按钮尺寸
- 将阶段轨道改为更紧凑的栅格展示
- 压缩参考视频、分镜图、分镜视频、最终成片的显示尺寸，更适配 9:16 短视频工作流
- 压缩右侧运行反馈、历史记录卡片的密度
- 补强 1360 / 1180 / 860 断点下的响应式规则，减少窗口缩小时的错位与混乱

## 不变项

以下内容本次未改动：

- `/clone` 五阶段业务流程
- ai666 / AtlasCloud / GRS.AI 透传机制
- GLOBAL_LOCK / PRODUCT_FIX / MODEL_CONSISTENCY 相关业务逻辑
- 任务状态机和历史恢复逻辑
- 分镜视频失败恢复与 taskId 查询逻辑

## 使用说明

本次修改无需新增用户操作。

用户仍按原流程使用：

1. 上传参考视频
2. 分析脚本
3. 生成并选择脚本变体
4. 上传商品图与选择模特
5. 生成分镜
6. 生成分镜视频
7. 合成最终成片

## 验证要求

- 运行 `npm run typecheck`
- 启动应用后打开 `/clone`
- 检查参考视频区、脚本区、分镜区、视频区、历史区在普通窗口和缩小窗口下都能稳定显示
- 检查视频和图片预览尺寸明显收口，不再显得过大
- 检查右侧栏不会再抢占过多视觉空间
