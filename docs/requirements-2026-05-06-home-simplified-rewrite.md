# 2026-05-06 首页简化重写

## 背景

原首页信息堆叠过多，同时存在历史结构残留和文本异常，已经不适合继续在原页面上修补。

本轮目标不是继续增加模块，而是把首页收回到“总览工作台”职责：

- 只负责入口
- 只负责状态
- 只负责下一步判断
- 不承担复杂编辑

## 本轮范围

仅重写：

- `D:\phpstudy_pro\WWW\videogenerate\src\renderer\src\ui\views\HomeView.vue`

不修改：

- 后端接口
- IPC 语义
- `/clone`
- `/settings`
- 模板和任务系统的数据来源

## 设计原则

本轮首页遵循 `DESIGN.md` 和现有工作台方向，重点控制复杂度：

1. 首屏必须看到主入口、当前任务、下一步
2. 首页不再承担复杂说明和拼贴式模块堆叠
3. 右侧只保留轻量摘要，不和主内容抢视觉
4. 继续保持深色专业工作台风格

## 新首页结构

首页现在固定为三段：

1. Hero
   - 左侧：产品定位、唯一主入口、次入口
   - 右侧：当前任务、下一步
2. KPI
   - 今日生成
   - 今日耗时
   - 成功率
   - 任务总数
   - 预计收益
3. 主体工作区
   - 左侧：进行中任务、流程状态、推荐模板
   - 右侧：快速创建、运行摘要

## 数据策略

本轮继续复用现有接口：

- `window.api.tasks.list()`
- `window.api.templates.list()`

没有新增假接口，也没有改动现有业务流。

## 页面职责边界

首页现在只做：

- 任务总览
- 任务入口
- 流程摘要
- 模板入口
- 运行提醒

首页不再做：

- 复杂编辑
- 大量说明性卡片
- 多层嵌套操作面板
