# VideoGen 产品说明

VideoGen 是一套面向 AI 视频生产团队的桌面端工作台，覆盖复刻、模特库、商品库、模板中心、任务执行和直播切片等核心能力。

## 当前模块结构

### 1. 首页 `/home`
- 作为工作台总入口。
- 展示核心模块入口和基础工作流引导。

### 2. 复刻 `/clone`
- 绑定模特与商品库商品。
- 基于参考视频生成脚本、分镜图和分镜视频。
- 保留失败重试、历史恢复和项目详情链路。

### 3. 模特库 `/models`
- 统一管理模特身份与参考素材。
- 支持模特筛选、复用和绑定到复刻项目。

### 4. 商品库 `/products`
- 商品列表页负责搜索、排序、创建商品。
- 商品详情页负责图片上传、封面设置、图片删除、备注和 `Product Canonical Source`。
- 商品库只负责商品事实源，不承担生产入口职责。

### 5. 生产 `/production`
- 生产模块是任务执行中心。
- 正式路由结构：
  - `/production`
  - `/production/create`
  - `/production/tasks`
  - `/production/tasks/:taskId`
  - `/templates`
- 页面职责：
  - 生产首页：摘要、最近任务、入口导航
  - 新建任务：选择商品、模板、数量、输出目录并提交
  - 任务列表：查看状态、筛选、批量控制
  - 任务详情：查看日志、错误、报告和输出目录
  - 模板中心：只管模板规则，不直接管理商品

### 6. 模板中心 `/templates`
- 管理结构规则、字幕、配音、音频和视觉输出规则。
- 与商品库解耦，不再反向塑造商品结构。

### 7. 切片 `/live-slicer`
- 处理直播长视频导入、切片与导出。

### 8. 设置 `/settings`
- 维护模型、接口与运行配置。

## 当前主流程

### 复刻主流程
1. 进入 `复刻`
2. 选择模特
3. 选择商品库商品
4. 生成脚本
5. 生成分镜图与分镜视频

### 生产主流程
1. 进入 `商品库` 创建商品并上传图片
2. 在商品详情中确认封面与标准源状态
3. 进入 `生产 -> 新建任务`
4. 选择商品和模板并提交任务
5. 在 `任务中心` 查看状态
6. 在 `任务详情` 查看日志、错误和输出

## 设计原则

- 前后端分离
- 低耦合、高内聚
- 模块化开发
- 商品一致性优先
- 参考图优先级最高
- 不允许用 cinematic 覆盖商品 identity
- Windows 开发与 Linux 部署兼容

## 当前实现说明

- 旧 `/tasks` 和 `/tasks/:taskId` 仅保留兼容跳转。
- 正式生产任务入口统一使用 `/production/tasks` 和 `/production/tasks/:taskId`。
- 商品库与生产已拆分为并列模块，不再共享“工作台”语义。
