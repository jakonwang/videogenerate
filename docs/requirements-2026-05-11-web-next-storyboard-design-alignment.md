# 2026-05-11 Web-Next 分镜设计页设计稿对齐

## 背景

- 当前 `apps/web-next/app/clone/[projectId]/page.tsx` 的第三阶段仍偏单列卡片流，不符合用户提供的暗色分镜设计稿。
- 设计稿强调的是桌面端高密度分镜编排工作台，而不是大卡片浏览页。
- 本轮继续只处理 `apps/web-next`，不改后端 API 协议与任务数据结构。

## 目标

- 将 `/clone/[projectId]` 的 `generate_storyboard_grids` 阶段精修为更接近设计稿的桌面端工作台：
  - 顶部视图切换与工具条
  - 中部高密度分镜表格
  - 右侧分镜预览、AI 优化建议、分镜素材库
- 保持现有分镜相关接口动作不变：
  - 批量生成分镜
  - 单镜头重生
  - 锁定 / 解锁
  - 编辑镜头
  - 添加镜头
- 减少布局冲突：
  - 分镜阶段隐藏外层运行侧栏
  - 避免出现双右栏挤压主工作区

## 实现说明

- 修改文件：
  - `apps/web-next/app/clone/[projectId]/page.tsx`
- 本轮实现内容：
  - 第三阶段标题改为“分镜设计”
  - 新增顶部“分镜视图 / 脚本视图”切换样式
  - 新增工具条按钮：
    - 一键优化
    - 分镜设置
    - 智能生成分镜
    - 批量替换
    - 镜头模板
    - 调色风格
    - 画面比例
  - 主区由原单列卡片改为表格式分镜列表：
    - 镜头
    - 画面 / 提示词
    - 时长
    - 景别
    - 运镜
    - 台词 / 旁白
    - 操作
  - 右侧新增阶段内专属侧栏：
    - 分镜预览
    - AI 优化建议
    - 分镜素材库
  - 当前镜头支持选中联动右侧预览
  - 分镜阶段切换为单主栏外层布局，隐藏共享 `RuntimeSidebar`

## 边界

- 不修改 `services/api` 和桌面端 Electron / Vue 页面。
- 不增加新的后端接口。
- 不改动任务详情页其他阶段的业务流程。
- Windows 本地开发与 Linux 部署保持兼容。

## 使用说明

- 本地验证命令：
  - `npm run typecheck:web-next`
  - `npm run build:web-next`
- 页面验收重点：
  - 分镜阶段主区是否已为高密度表格工作台
  - 分镜阶段是否只保留一个右侧专属栏
  - 表格列信息是否比旧卡片流更接近设计稿
  - 镜头选中后右侧预览是否联动
