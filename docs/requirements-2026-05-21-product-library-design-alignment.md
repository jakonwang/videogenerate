# 2026-05-21 商品列表设计稿对齐

## 目标

- 按最新设计稿重做 `/products` 商品列表页主工作区布局。
- 保留当前商品列表主链路：
  - 新建商品
  - 搜索
  - 类型筛选
  - 状态筛选
  - 排序
  - 网格/列表切换

  - 删除商品
