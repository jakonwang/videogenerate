# 2026-05-16 Clone 分镜图生成列表设计稿对齐

## 目标

- 将 `/clone/[projectId]` 中“分镜图片生成”阶段的结果列表，从原卡片式结果区改为接近设计稿的表格化行结构。
- 保持最小改动原则，只处理分镜图结果列表，不改右侧预览区、不改后端协议、不改其他阶段。

## 问题定位

- 原结果区更偏卡片网格，适合看单卡，但不适合横向比较多个镜头字段。
- 用户提供的设计稿更强调逐行对照：
  - 镜头编号
  - 缩略图
  - 提示词
  - 时长
  - 景别
  - 运镜
  - 台词 / 旁白
  - 操作
- 旧结构中操作入口与字段分散，视觉上不够像生产工作台。

## 本轮最小改动

- 修改文件：
  - `src/renderer/src/ui/views/CloneView.vue`

- 具体调整：
  - 新增 `storyboardDesignRows` 的列表渲染结果承接设计稿字段。
  - 将“分镜图片结果”区改为表头 + 行列表结构。
  - 每行包含：
    - 左侧镜头编号块
    - 缩略图
    - 提示词与标签
    - 时长
    - 景别
    - 运镜
    - 台词 / 旁白
    - 预览 / 锁定 / 重生成功能按钮
  - 将外层行容器从嵌套按钮结构改为可聚焦 `div` 行，避免按钮嵌套导致点击异常。
  - 为新表格结构补充独立样式，维持当前桌面端深色高密度工作台视觉。

## 结果

- 分镜图生成列表更接近用户提供的设计稿结构。
- 用户可以在同一行快速读取镜头关键信息并执行操作。
- 保留原有能力，不引入新的状态管理或接口改动。

## 使用说明

1. 进入桌面端 `/clone/[projectId]` 详情页。
2. 切换到“分镜图片生成”阶段。
3. 在“分镜图片结果”区域查看新的表格化列表。
4. 可直接在对应行使用：
   - 预览
   - 锁定 / 解锁
   - 重新生成

## 验证

- Windows 开发环境执行：
  - `npm run typecheck`

- 验收重点：
  - 列表为表头 + 多行结构，而非旧卡片网格。
  - 每行字段顺序与设计稿一致。
  - 行点击可选中镜头。
  - 行内操作按钮可单独点击，不受外层点击冲突影响。
