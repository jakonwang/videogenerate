# 2026-05-11 Web-Next 视频参考分析页设计稿对齐

## 背景

- 当前 `apps/web-next/app/clone/[projectId]/page.tsx` 的第一阶段更偏“素材准备页”，和最新暗色设计稿中的“参考视频分析结果页”不一致。
- 设计稿强调的是结果导向布局：
  - 左侧参考视频
  - 右侧内容结构识别
  - 下方 AI 分析结果、脚本预览、AI 引擎状态
  - 底部主操作按钮
- 本轮继续只处理 `apps/web-next`，不改后端协议。

## 目标

- 将 `upload_analyze_script` 阶段精修为更接近设计稿的分析结果工作台：
  - 顶部阶段标题与主动作
  - 中部视频预览与内容结构
  - 下方分析结果、脚本预览、AI 引擎状态
  - 底部“下一步 / 重新分析”
- 第一阶段同样隐藏外层共享运行侧栏，避免设计稿结构被双右栏挤窄。

## 实现说明

- 修改文件：
  - `apps/web-next/app/clone/[projectId]/page.tsx`
- 本轮实现内容：
  - 第一阶段标题改为“参考视频分析”
  - 顶部动作改为“保存项目 / 下一步：脚本生成”
  - 左侧保留参考视频上传与预览
  - 右侧改为内容结构识别卡组
  - 下方新增：
    - AI 分析结果
    - 脚本预览
    - AI 引擎状态
  - 底部改为主操作区：
    - 下一步：脚本生成
    - 重新分析
  - 第一阶段切换为单主栏外层布局，隐藏共享 `RuntimeSidebar`

## 边界

- 不修改后端分析协议与分析结果数据结构。
- 不新增新的分析接口。
- 仍保持商品图、模特等数据边界在当前页面能力内。
- Windows 本地开发与 Linux 部署保持兼容。

## 使用说明

- 本地验证命令：
  - `npm run typecheck:web-next`
  - `npm run build:web-next`
- 页面验收重点：
  - 第一阶段是否已改为分析结果导向布局
  - 外层共享右栏是否在第一阶段隐藏
  - 视频预览、结构识别、分析结果、脚本预览、引擎状态是否分区清晰
  - 底部主按钮是否更接近设计稿的操作节奏
