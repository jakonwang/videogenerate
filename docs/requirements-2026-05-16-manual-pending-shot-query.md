# 2026-05-16 分镜视频待回写手动查询入口

## 目标

- 为分镜视频阶段增加一个明确的“手动查询待回写”入口。
- 让用户在自动轮询之外，可以主动触发所有待回写镜头的任务查询。

## 问题定位

- 之前只有两种方式：
  - 整体“同步云端状态”
  - 单镜头“继续查询”
- 当有多个镜头处于待回写状态时，缺少一个批量、明确、低成本的主动查询入口。

## 本轮最小改动

- 修改文件：
  - `src/renderer/src/composables/useCloneProjectWorkspace.video.ts`
  - `src/renderer/src/composables/useCloneProjectWorkspace.ts`
  - `src/renderer/src/ui/views/CloneView.vue`
- 新增方法：
  - `syncPendingShotVideos()`
- 查询范围：
  - 仅查询有 `taskId` 且未生成真实视频文件的分镜
  - 包含状态：
    - `pending`
    - `idle`
    - `remote_running`
    - `polling_timeout`
    - `downloading`
    - `creating`
    - `generating`
    - `failed`
- UI 入口：
  - 分镜视频列表顶部新增按钮：`手动查询待回写`

## 结果

- 用户可以一键主动轮询所有待回写镜头。
- 不需要逐个点击“继续查询”。
- 保留原有单镜头查询和整体状态同步入口。
- 修正说明：
  - 原“同步云端状态”按钮此前只做本地项目刷新，没有真正触发远端视频任务对账。
  - 现已改为：
    - Electron 桌面端走 `reconcileRemoteStoryboardVideos`
    - Web 已登录场景逐个调用 `syncCloneShotVideoTask`
  - 因此“同步云端状态”现在会真正去查询远端分镜视频任务结果。
- 状态显示补充：
  - 不再只笼统显示“待继续查询”
  - 现在会区分：
    - `已完成`
    - `云端生成中`
    - `结果下载中`
    - `查询超时`
    - `云端失败`
    - `待补任务号`
  - 对于没有 `taskId` 的镜头，会明确提示“当前镜头没有 taskId，无法继续查询”

## 使用说明

1. 进入分镜视频阶段。
2. 如果存在“待继续查询”或其他待回写镜头，点击 `手动查询待回写`。
3. 系统会依次查询当前项目中所有待回写分镜任务，并更新页面结果。

## 验证

- Windows 开发环境执行：
  - `npm run typecheck`
