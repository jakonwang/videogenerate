# 2026-05-16 Clone 详情页细粒度列表局部刷新

## 目标

- 在上一轮“同项目对象原地更新”的基础上，继续减少自动运行期间列表区域的整块重绘。
- 重点优化高频更新的分镜图片、分镜视频、蓝图镜头数组。

## 问题定位

- 虽然同一项目已经不再整体替换，但数组字段如果每次都直接整体替换，Vue 仍可能让列表区域大范围重渲染。
- 自动运行场景下，最常变动的是：
  - `blueprint.shots`
  - `storyboardFrames`
  - `shotVideoOutputs`

## 本轮最小改动

- 修改文件：
  - `src/renderer/src/composables/useCloneProjectWorkspace.project.ts`
- 新增数组原地补丁逻辑：
  - 优先按 `id`
  - 其次按 `shotId`
  - 再次按 `taskId`
- 当数组项可识别时：
  - 保留已有项对象引用
  - 只补丁更新变化字段
  - 删除已不存在的项
  - 追加新项
- 当数组项不可识别时：
  - 仍回退到整体替换，保持兼容

## 结果

- 自动运行视频生成时，单个镜头完成、失败、重试、返回视频地址，会更偏向只更新对应卡片。
- 分镜列表和视频列表的局部刷新体验更稳定。
- 对现有流程、接口、状态结构不做额外扩展。

## 使用说明

1. 进入 `clone` 项目详情页。
2. 运行自动分镜视频生成。
3. 观察镜头卡片更新，应更接近“单卡片变化”，而不是整个列表区域一起跳动。
