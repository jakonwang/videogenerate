# 2026-05-12 Web-Next `/clone` 列表页设计稿对齐

## 背景

- 当前 `apps/web-next/app/clone/page.tsx` 已经具备任务列表能力，但页面布局、任务卡信息密度、右侧说明栏和壳层状态区与最新设计稿差距较大。
- 本轮目标仅针对 `apps/web-next` 的 `/clone` 列表页与其直接相关壳层视觉做收口，不调整后端接口协议。

## 目标

- 将 `/clone` 列表页对齐到设计稿的深色工作台布局。
- 强化首屏信息层级：标题、筛选、任务卡网格、右侧弱辅助栏。
- 将任务卡调整为更贴近设计稿的四列高密度卡片结构。
- 补齐壳层左侧导航入口与顶部状态展示，使列表页整体观感与设计稿统一。

## 实现说明

- 修改文件：
  - `apps/web-next/app/clone/page.tsx`
  - `apps/web-next/components/app/app-shell.tsx`
  - `apps/web-next/components/clone/clone-stage-nav.tsx`
  - `apps/web-next/app/globals.css`
- 主要调整：
  - `/clone` 标题区、状态筛选条、排序工具区、分页区重排。
  - 任务列表改为四列卡片栅格，封面、状态、进度、步骤圆点与底部操作区重新收口。
  - 右侧栏保留“任务说明”和“最近切换”两块弱辅助信息。
  - 壳层补齐 `直播`、`生产`、`账户` 等导航入口，并在顶部加入主题切换与运行状态展示。

## 边界

- 不修改 `services/api` 协议和任务数据结构。
- 不新增前端状态管理库。
- 不扩展 `/clone/[projectId]` 业务流程，只修正列表页及直接相关导航壳层。

## 使用说明

- 本地验证命令：
  - `npm run typecheck:web-next`
- 验收重点：
  - `/clone` 首屏布局应接近设计稿的左主区加右侧辅助栏结构。
  - 任务卡应为四列密集展示，而不是宽卡两列布局。
  - 左侧导航和顶部状态区应与设计稿风格一致。
