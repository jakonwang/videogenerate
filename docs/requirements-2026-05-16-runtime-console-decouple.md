# 2026-05-16 运行控制台与主视图解耦

## 目标

- 继续降低 `CloneView` 在自动运行期间的连带重渲染。
- 让运行日志区域的频繁追加，不再直接拖动主页面主体一起更新。

## 问题定位

- 之前 `runtimeLogs`、`consoleCollapsed`、滚动定位逻辑都写在 `CloneView.vue` 内部。
- 每次日志新增、日志滚动、控制台开关，都可能让主页面模板一起参与更新。

## 本轮最小改动

- 新增组件：
  - `src/renderer/src/ui/components/clone/CloneRuntimeConsole.vue`
- `CloneView.vue` 调整：
  - 抽离底部运行控制台模板
  - 移除页面内部日志滚动 DOM 引用
  - 将折叠状态通过 `v-model:collapsed` 传入独立组件
- 控制台组件内部负责：
  - 日志列表渲染
  - 滚动到顶部
  - 折叠/展开按钮

## 结果

- 运行日志高频追加时，主页面主体更新范围进一步缩小。
- 日志区域变为独立渲染单元，减少和分镜区、视频区、成片区的耦合。
- 不改现有日志来源和交互方式。

## 使用说明

1. 打开 `clone` 项目详情页。
2. 启动自动运行或视频生成。
3. 观察底部控制台持续写日志时，主内容区应更稳定。

## 验证
