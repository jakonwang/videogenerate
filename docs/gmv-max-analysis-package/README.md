# GMV MAX 插件分析资料包

本资料包用于把当前 GMV MAX 插件的产品功能、页面结构和真实界面交给 GPT 进行分析。

## 文件说明

- `GMV-MAX-产品与页面说明.md`：当前产品定位、工作流程、十个页面、跨页面能力、安全边界和已知体验问题。
- `GPT-分析提示词.md`：可直接提交给 GPT 的分析任务和输出要求。
- `screenshots/`：十个页面在 `1440x900` 和 `1280x760` 两种窗口尺寸下的 20 张截图。

## 使用方法

1. 将整个 `gmv-max-analysis-package` 目录上传给支持文件和图片分析的 GPT。
2. 先让 GPT 阅读 `GMV-MAX-产品与页面说明.md`。
3. 再提交 `GPT-分析提示词.md` 中的提示词。
4. 要求 GPT 对照 `screenshots/` 中的图片验证每项界面判断，不要只根据文字推测。

## 资料边界

- 文档反映 2026-08-03 本地工作区中的当前实现。
- 文档描述现有事实和已经发现的体验问题，但不预设最终改版方案。
- AI Coach 是否可用取决于软件现有聊天模型配置。
- 截图包含真实店铺、商品和推广系列名称。上传外部服务前，请先确认这些数据允许共享。
