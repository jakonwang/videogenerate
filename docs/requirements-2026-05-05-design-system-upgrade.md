# DESIGN.md 设计系统升级说明

## 摘要

本次将 `DESIGN.md` 完整升级为新的 VideoGen UI Design System，作为后续所有页面与组件重构的统一视觉和交互基线。

## 升级原因

原有设计规范已不足以支撑当前产品定位：

- 系统不再只是普通后台工具
- 页面已进入“AI 视频生产工作台”阶段
- 需要围绕自动化生产、流程闭环和商业化感知重建设计规则

## 本次覆盖内容

新的 `DESIGN.md` 已覆盖以下内容：

- 产品视觉定位
- 全局色彩系统
- 字体与信息层级
- 全局布局框架
- 页面背景与面板质感
- 核心组件规范
- 工作流步骤条规范
- AI 状态规范
- 首页 /clone / 参考分析 / 脚本生成 / 分镜设计 / 分镜视频 / 成片合成 / 发布导出页规范
- 导航规范
- 动效规范
- 信息密度规则
- 空状态与错误状态规范
- Codex 开发要求
- 推荐组件目录

## 使用原则

后续所有页面设计、重构、组件改造都必须优先以新的 `DESIGN.md` 为准。

特别是：

- 首页
- `/clone`
- 任务中心
- 模板库
- 模特库
- 产品素材库
- 设置中心

## 目标

统一后的设计规范要让用户明确感知到：

- 这是 AI Production Console
- 这是视频生产流水线
- 这是商业级内容工厂

而不是普通管理后台。
