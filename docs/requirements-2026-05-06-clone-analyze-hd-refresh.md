# 2026-05-06 `/clone` 爆款分析页高清稿对齐

## 背景

用户提供了 `/clone` 第一阶段“爆款分析 / 项目详情”高清参考图，要求将当前分析页按该设计稿进行精修。

本次只处理 `visibleStageKey === 'analyze'` 的前端展示层，不改后端链路、不改阶段状态机、不改模型透传逻辑。

## 修改范围

- `src/renderer/src/ui/views/CloneView.vue`
- `docs/requirements.md`

## 实现内容

### 1. 顶部工作流头部精修

- 保留面包屑 + 六阶段轨道
- 将顶部操作按钮改为更贴近设计稿的“保存项目 / 启动任务”
- 提升步骤节点尺寸、间距和高亮表现

### 2. 分析态三栏工作台重排

- 左侧：参考视频分析 + 视频信息
- 中间：分析结果 tabs、内容结构、脚本预览、爆款潜力评分
- 右侧：项目信息、标签、复刻模式、关联模特、关联产品

### 3. 视频分析主卡对齐

- 参考视频预览从更窄的竖屏比例调整为贴近设计稿的宽卡预览
- 去掉原有底部细小进度条，保留更简洁的信息组织
- 视频信息字段改为更接近稿件语义

### 4. 分析结果区精修

- tabs 改为更接近稿件的细线高亮样式
- “内容结构”卡片强化标题、描述和五段式结构卡
- “脚本预览”与“爆款潜力评分”卡片在视觉密度上收紧
- 评分卡补充趋势感装饰线

### 5. 右侧项目信息卡精修

- 项目名称输入展示增加字数占位
- 标签区补足展示密度
- 保留“智能复刻 / 自定义复刻”双模式卡
- 新增“高级设置”折叠位，和设计稿语义对齐

### 6. 底部任务队列与引擎状态

- 保留任务队列、AI 引擎状态原有数据来源
- 调整字号、卡片高度、间距与信息密度
- 更贴近参考图的控制台式工作台风格

## 不做的内容

- 不改 `createBlueprint` / `refreshCurrentProject` / 项目恢复逻辑
- 不改 `/clone` 其他阶段页面结构
- 不改 IPC 接口
- 不改任务状态推进逻辑

## 使用说明

Windows 开发环境运行：

```bash
npm run dev
```

打开 `/clone`，停留在第一阶段分析态查看效果。

验证命令：

```bash
npm run typecheck
```

## 验收标准

1. `/clone` 分析态整体结构和参考稿接近：顶部工作流 + 左中右三栏 + 底部队列区
2. 参考视频、分析结果区、项目信息区的视觉密度明显提升
3. 不影响 `/clone` 现有分析启动和后续步骤切换逻辑
4. `npm run typecheck` 通过
