# 2026-05-11 Web-Next `/workspace` 首页设计稿对齐

## 背景

本轮继续只处理 `apps/web-next`，不改后端 API 协议。

用户补充了新的首页设计稿，并明确目标页面不是公开站 `/`，而是登录后工作台首页：

- `apps/web-next/app/workspace/page.tsx`

设计稿目标特征：

- 深色专业工作台
- 左侧固定导航
- 顶部搜索 + 新建任务 + 通知 + 用户区
- 中部大 Hero 区
- 下方最近任务卡片区
- 下方推荐模板卡片区

## 本轮实现范围

### 1. `/workspace` 页面重排

首页已按设计稿方向收口为：

- 顶部 Hero 主视觉区
- 左侧主标题、副标题与双 CTA
- 右侧紫色 AI 立方体视觉区
- 最近任务卡片区
- 推荐模板卡片区

### 2. 壳层同步收口

`apps/web-next/components/app/app-shell.tsx` 已同步调整为更接近设计稿的工作台壳层：

- 左侧品牌区恢复为 `VideoGen + AI` 结构
- 左侧导航按工作台入口收口
- 顶部加入搜索框
- 顶部加入新建任务按钮
- 顶部加入通知按钮
- 顶部保留用户卡入口
- 左下角保留账户卡与退出操作

### 3. 文案清理

本轮同步清理了 `/workspace` 和 `AppShell` 中的高频乱码文案，统一回写为正常中文。

## 设计与实现约束

- 保持前后端分离
- 不把后端业务规则回灌到页面层
- 最近任务继续复用 `listCloneProjects()`
- 新建任务继续复用 `createCloneProject()`
- 推荐模板继续保持前端静态入口，不新增模板后端协议
- Windows 本地开发与 Linux 部署保持兼容

## 使用说明

### 本地开发

Windows 环境继续使用：

- `npm run dev:web-next`

默认访问：

- `http://127.0.0.1:18280/workspace`

### 本地验证

建议执行：

- `npm run typecheck:web-next`
- `npm run build:web-next`

### 页面验证重点

- `/workspace` 需优先对齐用户提供的暗色首页设计稿
- 顶部搜索、新建任务、通知、用户区需处于同一水平带
- 最近任务需为卡片式结构
- 推荐模板需为横向四卡布局
- 首页中文文案不得出现乱码
