# 需求说明：`/clone` 改回按步骤单阶段显示

## 背景

2026-05-06 调整 `/clone` 页面时，前端曾回退到“单页堆叠全部阶段内容”的状态，导致参考分析、脚本变体、分镜拼图、分镜视频、合成检查全部同时显示，不符合既有产品要求，也破坏了工作流节奏。

用户明确要求：

- `/clone` 必须是分步操作
- 不是同一个页面把全部内容一次性展示出来

## 目标

- 恢复 `/clone` 的按步骤工作流体验
- 顶部步骤条作为阶段切换入口
- 主工作区每次只渲染当前步骤内容
- 右侧运行反馈与历史记录继续常驻
- 不改后端接口、不改任务语义

## 本次实现

文件：

- `src/renderer/src/ui/views/CloneView.vue`

### 1. 新增前端阶段选择状态

- 增加 `selectedStageKey`
- 增加 `workflowStageKey`
- 增加 `visibleStageKey`

逻辑说明：

- `workflowStageKey` 负责把当前项目 `workflowV2.currentStep` 映射为五个阶段之一
- `selectedStageKey` 负责用户主动点击顶部步骤条时的显示切换
- `visibleStageKey` 作为当前实际渲染阶段

### 2. 顶部步骤条改为可点击

- 原先步骤卡只是状态展示
- 现在步骤卡改为按钮，可点击切换查看阶段内容
- 当前显示阶段高亮，不再依赖旧的“全部同屏渲染”

### 3. 主工作区改为单阶段渲染

按阶段拆分显示：

- `analyze`
  - 参考视频分析区
- `variant`
  - 脚本变体评分区
- `grid`
  - 模特选择 / 商品图上传 / 分镜拼图区
- `video`
  - 分镜视频生成区
- `compose`
  - 合成前检查 + 最终成片区

### 4. 自动跟随项目真实进度

- 新增监听 `workflowStageKey`
- 当项目状态推进时，前端会自动把当前显示步骤切到项目实际所处阶段
- 新建草稿时默认回到 `analyze`

### 5. 右侧摘要补充当前步骤信息

- 右侧运行反馈区新增“当前步骤”摘要卡
- 显示当前阶段标题与说明，避免切换后用户丢失上下文

## 结果

- `/clone` 不再是长页面堆满全部模块
- 页面恢复为工作流式单阶段界面
- 更符合：
  - `docs/requirements-2026-05-01-clone-simple-flow.md`
  - `docs/requirements-2026-05-05-clone-step-distributed-ui.md`
  - `docs/requirements-2026-05-06-workbench-architecture-refactor.md`
