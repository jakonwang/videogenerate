# TikTok 爆款复刻工坊增量说明（2026-05-01）

## 本次新增

### 1. 真实素材优先
- `/clone` 在单条分镜生成和“补齐所有 AI 分镜”前，会先尝试从当前项目绑定的产品素材库中匹配真实视频。
- 命中后直接复用本地真实素材，不再继续请求 GPT Image 或云端图生视频。
- 命中结果会回写：
  - `assetMatchScore`
  - `assetMatchReasons`
  - `selectedAssetId`
  - `replacementMode = local_video`

### 2. 高风险分镜门禁
- `realismRisk=high` 的分镜默认建议实拍，不自动 AI 生成。
- 用户只有在开启“强制 AI 生成”后，才允许继续走 AI 补镜。
- 批量补齐会自动跳过高风险且未强制 AI 的分镜。

### 3. 批量补齐排序优化
- “补齐所有 AI 分镜”会优先处理：
  - 低风险分镜
  - 短时长分镜
  - 未完成且未命中真实素材的分镜

### 4. 云任务池可见化
- `/clone` 第 3 步新增云任务池状态显示：
  - 排队数
  - 运行数
  - 完成数
  - 失败数
  - 暂停 / 继续

### 5. 爆款结构模板元信息
- `/templates` 现在会展示来自 `clone_blueprint` 的模板元信息：
  - 钩子类型
  - 商品类目
  - 节奏信息
  - 视觉风格

## 使用说明

### 复刻时降低成本
1. 先在产品素材库补充真实视频。
2. 再进入 `/clone` 分析参考视频。
3. 在第 3 步查看每个分镜是否已命中“真实素材匹配”。
4. 仅对未命中、且风险可接受的分镜继续 AI 生成。

### 保存模板
- 在 `/clone` 第 3 步当前分镜操作区的高级设置里，可直接：
  - 保存为爆款结构模板
  - 转成普通模板

## 验证
- Windows 开发环境已执行：
  - `npm run typecheck`
  - `npm run build`
- 两项通过。
