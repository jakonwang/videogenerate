# `/clone` 视频直出生产线需求说明

## 目标

将 `/clone` 默认流程收敛为最短链路：

1. 上传参考视频
2. 自动分析并增强提示词
3. 选择模特与场景
4. 直接生成视频并自动保存
5. 在历史记录中可回看、复用、再次生成

默认界面不再展示分镜九宫格、Top3 方案池、批量工作台等复杂入口，这些能力仅作为高级模式保留。

## 默认界面

- 参考视频区
- 提示词区
- 模特区
- 场景与产品区
- 结果历史区

## 主进程职责

- 参考视频分析
- 提示词增强
- 模型配置透传
- 视频生成与结果保存
- 项目历史读写

## 渲染进程职责

- 选择文件
- 展示状态、提示词、预览和历史
- 触发 IPC
- 不承载生成业务逻辑

## 模型规则

- 视频模型按用户当前设置透传
- 图片模型按用户当前设置透传
- 文案分析模型按用户当前设置透传
- 不允许静默切换内部默认模型
- 报错必须回显 provider、model、关键参数

## 提示词增强

提示词需要自动补充以下信息：

- 场景
- 主体
- 动作
- 镜头
- 光线
- 构图
- 材质
- 节奏
- 时长
- 负面约束

目标是把用户原始提示词扩写成更接近真实商业短视频的生成输入。

## 历史记录

每次生成后自动保存：

- 参考视频路径
- 提示词
- 模特
- 场景
- 模型信息
- 生成时间
- 输出视频路径

历史列表支持再次打开和复用。

## 验收点

- 上传参考视频后可生成蓝图
- 提示词可自动增强
- 可选择模特并继续生成
- 视频生成后自动进入历史列表
- 默认页不再展示旧工作台
- Windows `npm run typecheck` 通过
- Windows `npm run build` 通过
