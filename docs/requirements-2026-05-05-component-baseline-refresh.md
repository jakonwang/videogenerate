# 全局组件基线统一说明

## 摘要

本次调整以 `VideoGen_Component_Spec_Vue_Code.md` 为唯一组件规范基线，先统一全站基础样式层和设计系统组件层，不继续先改单个业务页面。

目标是先解决以下问题：

- 全站按钮、卡片、输入框风格不一致
- 侧栏、顶栏、工作区层级漂移
- 同时存在多套旧主题覆盖，导致页面观感不稳定
- 业务页即使结构没改，也会因为底层组件不统一而继续变丑

## 本次修改范围

文件：

- `src/renderer/src/styles.css`
- `docs/requirements.md`

规范来源：

- `VideoGen_Component_Spec_Vue_Code.md`
- `DESIGN.md`

## 本次统一内容

### 1. 全局 Token 对齐

将全局最终覆盖层收口到以下组件规范语义：

- 背景：`#0F1115`
- 卡片：`#161920`
- 主色：`#7C3AED`
- 边框：`rgba(255,255,255,0.06)`
- 高优先级文本：`#F8FAFC`
- 低优先级文本：`#94A3B8`
- 卡片圆角：`16px`
- 内层控件圆角：`8px`

### 2. 布局骨架统一

统一以下基础布局尺寸：

- 侧栏宽度：`220px`
- 顶栏高度：`64px`
- 页面内边距：`24px`
- 模块间距：`16px`

并保留窄屏时的侧栏压缩规则，避免窗口缩小时直接错乱。

### 3. 基础组件统一

统一以下组件的最终表现：

- `ds-button`
- `ds-card`
- `ds-input`
- `ui-card`
- `ui-panel`
- `primary-button`
- `ghost-button`
- `danger-button`

要求：

- Primary 只保留一套紫色主按钮表现
- Secondary / Ghost 统一为低对比描边按钮
- Danger 统一为红色弱强调
- 输入框统一为 `8px` 圆角、同一 focus ring
- 卡片统一为深色面板，不再使用厚重阴影

### 4. 顶栏与侧栏收口

统一以下区域的密度与观感：

- `ds-sidebar`
- `ds-sidebar__item`
- `ds-topbar`
- `ds-topbar__actions`
- 顶部搜索 / 顶部工具按钮 / 侧栏底部按钮

目标是让全站先回到“专业工具工作台”的基础状态，而不是继续出现后台页、浅色卡片页、旧设计页混搭。

## 不包含内容

本次不包含：

- `/clone` 业务流程调整
- 后端接口链路调整
- ai666 / AtlasCloud / GRS.AI 透传机制改动
- GLOBAL_LOCK / PRODUCT_FIX / MODEL_CONSISTENCY 逻辑改动
- 页面级大规模重排

## 使用说明

后续所有页面精修必须遵循：

1. 先复用现有统一基础组件和 token
2. 再做页面结构优化
3. 不允许重新引入新的按钮、卡片、输入风格
4. 新页面或新模块优先对齐 `VideoGen_Component_Spec_Vue_Code.md`

## 验证要求

- 运行 `npm run typecheck`
- 启动应用并检查侧栏、顶栏、卡片、按钮、输入框是否风格统一
- 检查窗口缩小时侧栏不会直接错位
- 检查设置页和首页不会再出现明显不同的基础控件风格
