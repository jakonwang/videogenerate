# 全站基础设计基线重整

## 摘要

根据项目根目录 `DESIGN.md`，将当前项目页面的基础设计层统一到同一套深色 Glassmorphism 设计系统，不再继续以局部页面补丁方式修 UI。

## 本次调整范围

- 全局颜色变量改为以 `DESIGN.md` 为准：
  - 背景：`#15121b`
  - 容器层级：`#1d1a24 / #221e28 / #2c2833`
  - 主色：`#d2bbff / #7c3aed`
  - 辅色：`#00eefc`
- 字体与层级改为以 `Inter + PingFang SC` 为主
- 基础圆角、边框、按钮、输入框、卡片、顶栏、侧栏统一
- 左侧菜单恢复为宽侧栏主导航，不再使用过度压缩的窄图标栏作为默认基线
- 设置中心从弹窗改为菜单独立页面 `/settings`

## 目标

- 让所有页面先拥有统一的基础风格和设计语言
- 减少 `/clone`、`settings`、`home` 等页面之间的视觉割裂
- 避免后续继续出现“一个页面一个风格”的补丁式设计问题

## 说明

- 本次先做“基础设计层”统一，不等于所有业务页面已经精修完成
- 后续页面精修都必须以 `DESIGN.md` 为唯一基线继续推进
