# 2026-05-10 Web-Next 双主题与浅色主题独立化

## 目标

本轮不再把浅色主题处理成深色主题的简单反色，而是补一套可独立成立的高质量浅色视觉体系。

## 实施范围

- `apps/web-next/app/globals.css`
- `apps/web-next/components/theme/theme-provider.tsx`
- `apps/web-next/components/theme/theme-toggle.tsx`
- 公开站壳层
- 工作台壳层

## 本轮完成

### 1. 双主题切换

- 新增 `dark / light` 主题切换
- 使用本地持久化保存当前主题
- 公开站和工作台统一接入切换入口

### 2. 浅色主题 token 独立化

浅色模式单独定义：

- 根背景
- 工作台背景
- 营销页背景
- 面板背景
- 卡片背景
- 输入框背景
- 边框透明度
- 阴影强度

目标是让浅色主题具备：

- 更轻的环境阴影
- 更清晰但不刺眼的边框
- 更低饱和的背景层次
- 更克制的紫蓝点缀
- 更明确的文字层级

### 3. 工作台浅色模式精修

已单独优化：

- Sidebar 背景与层次
- 激活导航样式
- 项目 rail 卡片
- 顶部状态栏
- 搜索框
- 状态指标条
- 用户按钮与图标按钮
- 面板与卡片阴影
- 设置页勾选行

### 4. 公开站浅色模式精修

已单独优化：

- 顶部导航玻璃感
- Hero / panel 背景
- 营销卡片边框与 hover 阴影
- 次级按钮背景
- 指标卡和下载说明卡

## 验证

已执行：

- `npm run build:web-next`

结果：

- 通过

## 使用说明

- 默认可在公开站和工作台右上角切换主题
- Windows 本地开发与 Linux 部署均不依赖平台专属主题逻辑
- 主题仅处理展示层，不改变业务接口与路由行为
