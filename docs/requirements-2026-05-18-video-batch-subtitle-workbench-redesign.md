# 2026-05-18 视频批量加字幕工作台重设计

## 目标

- 将 `插件 -> 视频批量加字幕` 从“可用但偏功能堆叠”的桌面插件页，升级为更适合 1920 宽屏的现代 AI SaaS 工作台。
- 保持现有批量字幕主链路和后端接口不变，继续主打“静态标题批量贴片”模式。
- 优先提升首屏层级、三栏工作区、预览舞台与主操作闭环，不扩散到 `/clone` 或其他插件页。

## 本轮最小改动

- 仅重构 `src/renderer/src/ui/views/VideoBatchSubtitleView.vue`。
- 不新增状态管理，不改 Web API，不改主进程渲染逻辑。
- 只补充需求文档，不引入新的全局主题系统。

## 页面结构调整

- 顶部改为：
  - 大标题区
  - 教程入口
  - 轻量 KPI 概览
- 顶部步骤条改为四段胶囊流程：
  - 选择素材
  - 配置标题
  - 实时预览
  - 批量渲染
- 主体固定三栏：
  - 左栏：素材来源、上传区、成片库选择、已选素材列表、容量进度
  - 中栏：9:16 预览舞台、缩略轨道、预览状态、主 CTA
  - 右栏：字幕内容 / 样式设置双 tab
- 底部双区保留：
  - 任务队列
  - 输出结果与 GeeLark 推送

## 视觉规范

- 全页保持深色主题，沿用原有紫色主色但降低廉价感和饱和度。
- 所有主卡片统一为：
  - `20px` 圆角
  - 极浅边框
  - 柔和阴影
  - 轻微玻璃拟态背景
- 页面背景使用深色渐变与稀疏紫色氛围光，不做夸张发光。
- 保持充足留白，避免传统后台管理系统式表单堆叠。

## 交互说明

- 默认聚焦 `字幕内容`，避免首屏出现过多参数。
- `样式设置` 收敛为高频控制：
  - 模板选择
  - 字体
  - 字号
  - 描边
  - 阴影
  - 对齐与位置
- 继续复用既有方法：
  - `pickUploadVideos`
  - `applyCloneSources`
  - `runGenerateTitles`
  - `saveCurrentDraft`
  - `renderBatch`
  - `pushToGeelark`
- 预览加载、字体导入、AI 生成、批量渲染、GeeLark 推送均补统一禁用态和加载反馈。

## 使用说明

1. 进入 `插件 -> 视频批量加字幕`。
2. 选择本地上传或从成片库导入素材。
3. 在右栏 `字幕内容` 中输入统一标题，必要时使用 AI 生成文案。
4. 在 `样式设置` 中调整字体、字号、描边、阴影、位置等参数。
5. 在中间预览舞台确认真实叠加效果。
6. 点击 `保存当前配置` 保存草稿，或直接点击主按钮进行批量渲染。
7. 渲染完成后，在输出结果区查看视频、打开目录或推入 GeeLark 发布池。

## Windows / Linux 兼容说明

- 本地开发与测试环境为 Windows，部署环境为 Linux。
- 页面继续优先使用真实预览链路，不引入只在浏览器端生效的字幕渲染逻辑。
- 静态标题贴片已改为 React + Remotion 渲染中间视频，再由 FFmpeg 封装输出。
- 本插件不再提供自定义字体导入入口，默认使用项目可解析的标准字体族名称。

## 2026-05-18 补充：React + Remotion 中间视频渲染链路

- 目标：
  - 将静态标题贴片的渲染从旧的 SVG/位图拼装逻辑切换为 `React 写字幕 -> Remotion 直接渲染中间视频 -> FFmpeg 最终封装/转码`。
- 实现方式：
  - 主进程新增 Remotion 字幕层模块。
  - 使用 React 组件描述字幕排版、描边、阴影、对齐和位置。
  - Remotion 直接输出无音轨中间视频。
  - FFmpeg 负责复用原始音轨并输出最终成片。
- 当前边界：
  - 本轮先替换静态标题贴片模式。
  - 时间轴字幕和 ASS 字幕链路暂不改为 Remotion。
  - 自定义字体导入、字体来源区分和批量字幕字体接口已从该插件链路移除。
  - 为避免主进程构建被 Remotion 的 webpack 依赖链污染，Remotion 相关包改为运行时动态加载，并在 Electron 主进程打包时外置。
- 使用说明：
  - 用户侧入口不变，仍在 `视频批量加字幕` 页面操作。
  - 标题、字号、描边、阴影调整后，预览与最终导出均基于 Remotion 中间视频链路生成。
- 验证方式：
  - `npm run typecheck`
  - `npm run build`
