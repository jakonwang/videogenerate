# 产品文案资料包输出说明

## 摘要

本次新增一组面向外部展示与内部交付的产品文案资料，方便官网、销售、README 和产品介绍页直接复用。

## 新增文档

- `docs/product-overview.md`
- `docs/official-website-copy.md`
- `docs/sales-onepager.md`
- `docs/README-product.md`

## 文档用途

### 1. `product-overview.md`

用于产品功能介绍页、招商页、产品手册首页等场景。

### 2. `official-website-copy.md`

用于官网模块化功能介绍文案，便于前端页面直接拆区块使用。

### 3. `sales-onepager.md`

用于销售演示、客户介绍、PPT 一页式能力说明。

### 4. `README-product.md`

用于 README / docs 形式的产品说明文档，适合项目资料、交付说明和内部共享。

## 输出原则

- 以当前系统真实已有功能为基础整理
- 统一面向用户的表达方式
- 不使用仅开发内部可见的技术术语作为核心卖点
- 尽量保留“爆款复刻 + 模板生产 + 批量导出”这一主线

## 后续建议

- 官网页面后续可直接以 `official-website-copy.md` 为基线转为正式落地页
- 销售资料可继续补充行业场景版，如电商版、TikTok 代运营版、品牌内容版
- 如后续产品功能继续扩展，应同步更新这组文案资料
