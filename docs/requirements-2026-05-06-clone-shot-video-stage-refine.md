# 2026-05-06 `/clone` 分镜视频生成阶段精修

## 背景

`/clone` 第四阶段“分镜视频生成”原有卡片排版不稳定，存在以下问题：

- 视频卡信息层级混乱
- 卡片内部位置错乱，像临时堆叠
- 操作区不够像专业工作台
- 单镜重新生成入口不明确

本轮不改后端语义，只精修前端第 4 阶段展示结构。

## 修改范围

- `src/renderer/src/ui/views/CloneView.vue`

## 本轮调整

### 1. 重新整理视频卡结构

每张分镜视频卡统一为四段：

1. 顶部标题区
   - 分镜标题
   - provider / model
   - 状态标签
2. 中间视频预览区
3. 指标区
   - 时长
   - 远端状态
4. 底部操作区

### 2. 强化工作台信息层级

- 增加 `shot-card-title`
- 增加 `shot-metrics`
- 增加 `shot-actions`
- 让状态、指标、操作不再混在同一层

### 3. 单镜重新生成入口前置

原界面只有失败时才明显看到重新生成动作，不够直接。

本轮改为：

- 每个镜头都显示 `重新生成当前镜头`
- 失败镜头额外显示 `继续查询结果`

这样更符合生产工作台的“镜头级控制”预期。

### 4. 样式收口

- 顶部标题区改为更稳定的左右结构
- 指标区改为双列卡片
- 状态标签补充弱化型 `task` 标签
- 小屏下自动转为纵向堆叠

## 验证

已执行：

- `npm run typecheck`

结果：

- 通过

## 后续建议

如果继续精修 `/clone` 第四阶段，下一步建议：

1. 把分镜视频卡抽成独立组件
2. 把“远端状态 / taskId / 重试历史”做成可折叠诊断区

## 2026-05-06 Refine Pass 3

- 右侧固定侧栏改为“实时预览”模块，主要用于查看当前镜头视频、脚本摘要和参考分镜图
- 移除第 4 阶段中间区重复预览卡，只保留右侧预览侧栏
- 表格列宽与行高重新收紧，降低溢出、错位和竖排风险
- 顶部列表工具栏改为“标题 + 说明 + 轻操作”结构，不再保留卡片按钮感的伪 tabs
- 右侧预览块补充 `shot script`、`shot type`、`product role`、`taskId` 和 `provider/model` 摘要
- 验证命令包括 `npm run typecheck` 与 `npm run build`
