# 2026-05-11 `/clone` 任务卡片化改造

## 背景

- 当前 `apps/web-next/app/clone/page.tsx` 的任务列表虽然已经不是传统表格，但主体仍采用“表头 + 行列”式信息排布。
- 在中等宽度屏幕下，任务信息、阶段、进度、时间和操作区横向拥挤，不利于任务摘要浏览。
- 本轮继续只处理 `apps/web-next`，不修改后端 API 协议。

## 目标

- 将 `/clone` 列表区改为纵向堆叠任务卡片。
- 移除横向表头结构和类表格行布局。
- 保留以下能力与信息：
  - 打开任务
  - 删除任务
  - 阶段标签
  - 进度百分比与进度条
  - 更新时间
  - 封面缩略图
  - 标题
  - 描述
  - 参考视频
  - 模特
  - 错误摘要
- 不改现有筛选、分页、鉴权和 mutation 逻辑。

## 实现说明

- 文件：
  - `apps/web-next/app/clone/page.tsx`
- 实现方式：
  - 列表主体改为响应式卡片栈布局。
  - 每张卡片分为：
    - 左侧封面
    - 顶部标题区 + 阶段标签 + 操作按钮
    - 中部任务摘要信息
    - 右侧/下方阶段进度区
  - 继续复用现有深色面板、圆角、描边、悬浮发光和 `gradient-progress` 视觉样式。

## 边界

- 不新增字段，不改接口返回结构。
- 不把后端状态判断逻辑迁移到前端页面之外的新协议层。
- 保持 Windows 开发与 Linux 部署兼容。

## 验证

- `npm run typecheck:web-next`
- `npm run build:web-next`
