# /clone 分镜任务幂等与手动同步

## 摘要

本次补充 `/clone` 分镜视频生成的任务幂等性、乐观锁式同步与本地持久化策略，避免已有分镜被重复触发 AI 请求，并支持失败后先拉取云端最新状态再决定是否重跑。

## 功能要求

- `video_image_to_video` 调用前必须先执行本地任务检查：如果 `scene_videos` 目录已存在对应分镜视频，或项目数据中该分镜已是完成状态，则直接跳过，不得重新触发 AI 请求。
- ai666 / `apifox_hub` 视频任务在超时后必须保留 `taskId`，不得直接抹除分镜状态；失败卡片优先提供“手动拉取最新状态”入口。
- 每个分镜视频成功后必须立即持久化项目数据，保证进程崩溃后重启仍能识别已完成分镜。
- 批量继续生成时，只允许 `failed`、`pending`、`idle` 的分镜进入队列，`done`、`success`、`completed` 必须直接跳过。
- 超时或失败日志必须记录 `taskId`，便于后续查询与恢复。

## 使用说明

1. 在 `/clone` 完成分镜拼图后点击“继续生成剩余分镜视频”。
2. 如果某个分镜失败，先点击“手动拉取最新状态”。
3. 如果云端已经有结果，系统会同步并回写为完成状态。
4. 如果确认仍失败，再执行单镜重试。
