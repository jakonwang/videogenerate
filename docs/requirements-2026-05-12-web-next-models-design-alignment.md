# Web-Next 模特库页设计稿对齐

## 背景

- 目标页面：`apps/web-next/app/models/page.tsx`
- 参考设计稿：`C:/Users/Administrator/Desktop/设计图/暗色/模特页面.png`
- 本轮约束：
  - 只调整 `web-next` 的 `/models`
  - 不修改菜单栏和顶部栏
  - 优先保证首屏结构、卡片区和右侧详情区与设计稿接近

## 本轮实现范围

- 清理模特库页面的用户可见中文文案
- 保留左侧模特列表 + 右侧详情面板的工作台结构
- 保留标签、筛选、搜索、分页和“使用模特”入口
- 调整数据策略为“接口优先，本地 mock 回退”：
  - 接口成功时显示真实模特数据
  - 接口加载中时显示同步提示，同时可保留本地预览思路
  - 接口失败时不再让列表区整块空白，直接回退到本地模特卡片数据
