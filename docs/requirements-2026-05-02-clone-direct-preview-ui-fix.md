# `/clone` 直出预览与界面修复记录

日期：2026-05-02

## 本次目标

围绕 `/clone` 爆款复刻页，优先修复两个问题：

1. 默认“生成视频”会落回旧分镜预检，导致报错“分镜 #n: 缺少可用视频”。
2. 页面体验不符合当前产品方向，缺少紧凑布局、模特弹窗选择、产品缩略图和历史记录侧栏。

## 已完成改动

### 1. 主进程生成链路修复

文件：
- `src/main/modules/clone/service.ts`

改动点：
- `runStoryboardAndVideoBatch` 在进入默认预览链路前，会把当前上传的产品参考图回写到项目分镜运行态。
- 同时对默认直出链路写入 `forceAi: true`，避免高风险分镜在简化流程里被静默跳过。
- `renderPreview` 新增 `shotIds` 入参，允许只对当前选中方案的分镜做预检和渲染。
- 首条预览生成时，不再因为项目里其他未参与当前方案的分镜缺少视频而整体失败。

结果：
- 修复了“出片前检查失败：分镜 #1/#2/#3... 缺少可用视频”的主链路阻塞问题。

### 2. `/clone` 页面重构

文件：
- `src/renderer/src/ui/views/CloneView.vue`

改动点：
- 页面默认收敛为核心生产线：
  - 参考视频
  - 增强提示词
  - 模特与产品素材
  - 首条预览与历史记录
- 顶部新增紧凑状态条，明确当前阶段与下一步。
- 参考视频区域支持直接视频预览。
- 模特选择改为弹窗卡片式选择，不再使用简单下拉。
- 产品图改为真实缩略图展示：
  - 每行 3 个
  - 最多可见 3 行
  - 支持继续追加上传
- 右侧固定历史记录和运行状态区。
- 保留“高级模式”折叠入口，但不再占据默认主界面。

### 3. 媒体预览兼容

沿用项目已有 `vg://file?path=...` 安全协议显示本地视频与图片，兼容 Electron 渲染进程，不直接暴露主进程逻辑到 Vue 页面。

## 使用说明

1. 在 `/clone` 上传参考视频。
2. 点击“分析脚本”生成蓝图与增强提示词。
3. 选择模特，并上传产品参考图。
4. 点击“立即生成视频”。
5. 首条预览完成后可直接播放，结果会自动进入右侧历史记录。
