# 2026-05-12 桌面端 `/clone` 快速上线优化

## 背景

- 当前用户实际运行和验收的主界面来自桌面端 Electron + Vue，而不是 `apps/web-next`。
- `/clone` 主链路已经具备任务创建、阶段执行和成片输出基础能力，但仍存在：
  - 列表页中文乱码
  - 详情页阶段术语不统一
  - 壳层视觉过重，影响 `/clone` 主工作区层级
- 本轮目标是让桌面端 `/clone` 更接近可上线使用状态，而不是继续扩展协议或重做后端。

## 本轮目标

- 只处理桌面端 `/clone` 主链路，不同步实施 Web 端。
- 保留现有 5 阶段业务语义：
  1. 参考分析
  2. 脚本生成
  3. 分镜设计
  4. 分镜视频
  5. 成片合成
- 保留现有接口契约与数据来源，只调整展示层、布局层和文案层。

## 修改页面

- `src/renderer/src/ui/views/CloneTaskListView.vue`
- `src/renderer/src/ui/views/CloneView.vue`
- `src/renderer/src/ui/MainLayout.vue`

## 实现说明

### `/clone` 列表页

- 整页恢复正常中文文案。
- 顶部区统一为：
  - 页面标题与说明
  - 批量导出占位按钮
  - 新建任务按钮
  - 搜索框
  - 状态筛选
  - 更新时间排序与视图切换占位
- 任务卡继续保留：
  - 封面图
  - 当前状态标签
  - 当前阶段
  - 标题
  - 模特和素材摘要
  - 进度条与五步节点
  - 更新时间
  - 进入/删除操作
- 右侧 rail 收口为弱辅助区，只承接：
  - 任务说明
  - 后台持续运行提示
  - 详情页职责说明
  - 最近切换列表

### `/clone/:projectId` 详情工作台

- 保持现有阶段切换和数据驱动逻辑不变。
- 统一 5 阶段术语：
  - 参考分析
  - 脚本生成
  - 分镜设计
  - 分镜视频
  - 成片合成
- 统一阶段标题、按钮名称和说明文案，避免“脚本变体评分 / 分镜图片生成 / 合成最终成片”等旧命名混杂。
- 保留现有：
  - 上一步 / 下一步
  - 重新生成
  - 替换片段
  - 成片合成
  - 运行控制台

### 公共壳层

- 左侧底部信息区减重，去掉 GPU/API 伪运行面板。
- 顶部状态栏收口为：
  - 工作台状态
  - 算力余额
  - 用户信息
  - 帮助 / 钱包 / 更多
- 不修改导航结构，不引入新依赖。

## 明确不变的边界

- 不修改 `src/preload/index.ts` 中 `window.api.clone.*` 契约。
- 不修改 `src/main/modules/clone/*` 后端业务逻辑。
- 不新增服务端字段。
- 不改 `/clone`、`/clone/:projectId` 路由结构。
- 不新增状态管理方案，不重做前后端通信层。

## 验收口径

### 本地命令

- `npm run typecheck`
- `npm run dev`

### 页面验收

- `/clone`
  - 页面正常渲染，无中文乱码
  - 新建任务可进入详情页
  - 删除任务仍可用
  - 搜索与状态筛选仍可用
  - 右侧说明 rail 独立存在
- `/clone/:projectId`
  - 5 阶段导航正常显示
  - 阶段切换、上一步、下一步正常
  - 关键按钮和入口不失效
  - 错误态、空态、处理中状态有明确反馈
- 壳层
  - 左侧导航与顶部栏风格统一
  - 不再用重状态面板干扰 `/clone` 主内容

## 兼容要求

- 本地测试环境为 Windows。
- 发布环境为 Linux。
- 本轮改动继续保持路径处理和界面逻辑跨平台兼容，不引入新的 Windows 专属业务依赖。
