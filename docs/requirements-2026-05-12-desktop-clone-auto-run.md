# 2026-05-12 桌面端 `/clone` 自动复制流程

## 目标

- 桌面端 Electron + Vue 的 `/clone` 主链路支持一键自动推进。
- 用户已选好参考视频、商品图、模特后，可直接自动执行到“分镜视频”阶段。
- 不自动进入最终成片合成。

## 本轮实现

- 主进程新增统一自动入口：
  - `cloneService.autoRunCloneToStoryboardVideos()`
- 自动阶段固定为：
  1. 分析参考视频
  2. 准备一致性素材
  3. 生成脚本候选
  4. 自动选择最高分脚本
  5. 生成分镜图片
  6. 生成分镜视频
  7. 停在分镜视频阶段
- 自动脚本路径统一使用：
  - `generateScriptVariantsForProject`
  - `selectScriptVariantForProject`
- 不再依赖 `buildScriptCandidates` 驱动后续自动链路。

## 重试策略

- 分镜图片：
  - 每镜头最多自动重试 2 次
  - 超过 2 次后保留镜头级失败原因
- 分镜视频：
  - 每镜头最多自动重试 2 次
  - 失败不会回滚已成功镜头
  - 超时/失败按镜头保留错误与重试次数

## 页面行为

- `CloneView.vue` 脚本阶段新增“自动继续到分镜视频”按钮。
- 详情页可见：
  - 自动流程摘要
  - 分镜图片失败数量
  - 分镜图重试次数
  - 分镜视频重试次数
  - 项目级自动状态

## 使用说明

- Windows 本地开发测试：
  - `npm run typecheck`
  - 启动桌面端后进入 `/clone/:projectId`
  - 完成参考视频、商品图、模特选择
  - 点击“自动继续到分镜视频”
- Linux 部署兼容性：
  - 本轮未引入 Windows 专属路径逻辑
  - 自动链路仍复用原有服务层与跨平台路径函数

## 验收重点

- 自动流程能停在“分镜视频”阶段
- 最高分脚本会被自动选中
- 分镜图片失败可见且最多自动重试 2 次
- 分镜视频失败可见且最多自动重试 2 次
- 项目状态可显示“完成 / 部分失败”
