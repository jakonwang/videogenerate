# 2026-05-06 首页精修第二轮

## 背景

首页已完成简化重写，但视觉层级还偏“普通仪表盘”，状态感和控制台感不够强。

本轮不改首页职责，只做信息层级和视觉密度精修，让页面更像生产工作台：

- 更快看懂当前任务
- 更快看懂下一步
- 更强的状态识别
- 更弱的装饰感

## 本轮修改范围

- `D:\phpstudy_pro\WWW\videogenerate\src\renderer\src\ui\views\HomeView.vue`

## 具体精修内容

### 1. Hero 收紧

- 增加 Hero 顶部统计块
- 当前任务卡补充进度与预计时间
- 保持 Hero 只表达：
  - 入口
  - 当前任务
  - 下一步

### 2. 模块标题统一

为首页核心模块补充小型 kicker：

- `Tasks`
- `Workflow`
- `Templates`
- `Quick Start`
- `Overview`

目的：

- 让信息分区更清楚
- 强化工作台节奏
- 降低“大标题堆叠感”

### 3. 任务列表更像控制台

- 新增表头
- 增强任务行底色和边界层级
- 新增状态 pill
- 让任务状态一眼可扫

### 4. 流程状态增强

- 当前活动节点增加更明确的高亮边框
- 强化“正在推进哪个阶段”的感知

### 5. 右侧侧栏收紧

- 快速创建卡减少松散感
- 运行摘要列表更像固定侧栏信息，而不是普通通知卡
