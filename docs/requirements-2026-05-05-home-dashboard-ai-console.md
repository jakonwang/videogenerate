# 需求文档：首页 Dashboard 重构为 AI Production Console

## 日期

2026-05-05

## 背景

当前首页虽然已经有基础入口，但仍然偏普通后台式卡片堆叠，和新的 `DESIGN.md` 设计基线不一致，主要问题：

- 首页层级不清晰，缺少“AI 视频生产工作台”的控制台感
- 信息密度不稳定，卡片比例过大，视觉显得笨重
- 缺少右侧独立信息栏，无法承载快速创建、AI 助手、通知等低频但高价值内容
- 不能直观看到任务状态、流程进展和模板入口

## 目标

把首页重构为更接近 VideoGen 工作台的结构，统一到新的设计系统语言：

- 左侧保留系统导航
- 中间为核心工作台
- 右侧为信息与辅助操作栏
- 首屏同时看到 Hero、KPI、任务状态、流程进展、模板入口、AI 助手和通知

## 本次修改范围

仅修改首页展示层与其样式，不改动后端接口和业务链路：

- `src/renderer/src/ui/views/HomeView.vue`
- `src/renderer/src/styles.css`

## 实现内容

### 1. 首页结构重做

首页改为两大列结构：

- 主工作台区
  - Hero 主视觉
  - 5 个 KPI 指标卡
  - 进行中的任务
  - 任务流程可视化
  - 推荐模板
- 右侧信息栏
  - 快速创建
  - AI 助手
  - 系统通知

### 2. Hero 区重做

- 文案改为 AI 视频生产工作台语义
- 增加主 CTA：`开始新任务`
- 增加次 CTA：`导入参考视频`
- 用轻量视觉轨道和 AI 核心体块代替粗重的大图块

### 3. 数据卡重做

统一展示以下 5 个关键指标：

- 今日生成视频
- 今日消耗时长
- 成功率
- 任务总数
- 预计收益

### 4. 任务面板重做

展示任务表格式内容，包含：

- 任务名称
- 进度
- 当前步骤
- 耗时
- 预计剩余
- 状态

保留现有 `window.api.tasks.list()` 数据来源，不引入硬编码业务依赖。

### 5. 流程可视化面板

新增首页级任务流程摘要，强化“AI 自动生产视频”心智，展示：

- 分析参考视频
- 脚本生成
- 分镜图生成
- 分镜视频生成
- 视频合成
- 成片导出

### 6. 模板区重做

模板区改为更紧凑的推荐模板卡片，而不是旧的普通列表。

### 7. 右侧信息栏

新增：

- 快速创建：爆款复刻、批量生成、直播切片、模板应用
- AI 助手：建议问题入口和输入框
- 系统通知：任务、模板、系统状态

### 8. 响应式适配

为首页新增独立断点规则：

- 大屏保持工作台 + 右侧信息栏
- 中屏压缩 KPI 与模板网格
- 小屏下改为单列堆叠，避免布局错乱

## 约束与兼容

- 不修改 `/clone`、任务系统、模板系统的后端链路
- 不破坏现有路由与 `window.api.*` 接口
- 保持 Windows 开发环境与 Linux 部署环境兼容

## 验收标准

1. 首页首屏可同时看到主任务入口、数据状态、任务列表和右侧信息栏
2. 首页不再呈现普通后台堆叠感
3. 字号、卡片尺寸和间距明显收敛，避免“老人机大字大块感”
4. 缩小窗口时布局不乱
5. `npm run typecheck` 通过
