# 设置中心精修与 ai666 命名收敛

## 摘要

本轮针对设置中心继续做收敛优化，目标是降低普通用户理解成本，并统一聚合供应商的对外命名为 `ai666`。不改动现有主进程配置结构，不破坏旧配置兼容。

## 本次调整

### 1. 供应商收敛

- 视频侧用户可见供应商只保留：
  - `AtlasCloud`
  - `GRS.AI`
  - `ai666`
- 原内部供应商键 `apifox_hub` 继续保留，仅用于兼容现有存储和调用链。
- 原用户可见“聚合接口”全部改名为 `ai666`。

### 2. 设置页交互收缩

- 设置中心继续保留四个主分区：
  - 图生视频模型
  - 文生图模型
  - 对话模型
  - 七牛云配置
- 顶部说明区从大卡片压缩为紧凑工具条。
- 推荐配置由大卡片改为更短的快捷按钮。
- 成功/失败提示条高度收缩，减少首屏占用。

### 3. 新手 / 专业模式

- 新手模式：
  - 默认只展示当前主供应商必要字段
  - 高级参数折叠
- 专业模式：
  - 可展开更多高级能力
  - 但不再用一个全局开关同时撑开所有分区

### 4. 分区级高级设置

- 原全局 `settingsAdvancedOpen` 拆分为：
  - `videoAdvancedOpen`
  - `imageAdvancedOpen`
  - `chatAdvancedOpen`
- 视频高级设置拆分为两个较小区域：
  - 回退与兼容
  - ai666 多能力模型
- 图片和对话高级设置也改为独立展开，避免混乱。

### 5. ai666 推荐模型命名

- 当前推荐占位保持以下默认值：
  - 对话：`gpt-4.1-mini`
  - 图片：`gpt-image-1`
  - 图生/参考视频：`google/veo3.1-lite/image-to-video`
- 这些值用于推荐填充与占位，不改变“严格按用户保存设置透传”的原则。

## 兼容策略

- 不修改主进程已落地的 `apifox_hub` 配置结构。
- 已存在 `seedance` 的可见视频供应商值继续在前端自动归一到 `kling`。
- 保存配置后仍需重新读取回显，保证前端展示与实际持久化一致。

## 使用说明

### 普通用户

1. 打开设置。
2. 选择新手模式。
3. 只填写当前要用的视频、图片、对话模型和对应 Key。
4. 七牛云按需填写。

### 高级用户

1. 切换专业模式。
2. 进入对应分区展开高级设置。
3. 仅在确实需要时配置回退供应商、ai666 多能力模型或高级请求格式。

## 回归验证

- 设置中心仍可保存并重新读取全部配置。
- 用户可见文案不再出现“聚合接口”，统一显示为 `ai666`。
- 视频供应商下拉只保留 `AtlasCloud / GRS.AI / ai666`。
- 新手模式首屏高度明显收缩。
- 图片、对话、高级视频设置互不串联展开。
- Windows 环境通过：
  - `npm run typecheck`
  - `npm run build`
