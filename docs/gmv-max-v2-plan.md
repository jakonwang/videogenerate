# GMV MAX 优化器 V2 重构规划：一眼看懂、每天照做、持续赚钱

> 日期：2026-11-15
> 依据：TikTok 官方 GMV Max API / MCP 文档、TikTok 广告帮助中心官方文章、TikTok Shop 商家大学课程，对照现有插件代码（后端 `src/main/modules/tiktok-gmv-max/` 约 1.3 万行，界面约 2.7 万行）。
> 文中标注 **【官方】** 的规则来自 TikTok 官方资料；标注 **【经验】** 的是第三方或行业经验值，可在设置里调整。

---

## 一、为什么现在的插件不好用

### 1.1 概念太多，用户看不出「哪里有问题」

现有插件有 10 个页面（今日待办、经营概览、商品增长、素材优化、利润与成本、推广系列、待审批动作、自动化设置、操作记录、使用帮助），还有十多套内部概念：

- S1–S7 决策状态、P0/P1/P2 优先级、生命周期 / 成熟度 / 健康分
- SOP 周期、AI Coach、实验与观察锁
- shadow / pilot 执行模式、审批流

每个页面都在展示数字，但没有一句话告诉用户「这个系列现在的问题是 X，今天做 Y」。

### 1.2 做出来的动作和 GMV Max 实际能调的手段对不上

GMV Max 是全自动投放，**没有人群定向**。运营能动的只有下面几个手段 【官方】：

| 手段 | 对应接口 / MCP 工具 |
|---|---|
| 目标 ROI（Target ROI） | `campaign_gmv_max_update`（`roas_bid`） |
| 日预算 | `campaign_gmv_max_update`（`target_roi_budget`） |
| 投放模式：Target ROI / Max Delivery | `bid_type`：`CUSTOM` / `NO_BID`；Max Delivery 会话（session） |
| 商品选择 | 推广系列的商品范围 |
| 素材供给：授权、移除、加回 | `gmv_max_creative_update`（Remove or add back creatives） |
| Creative Boost（给潜力素材加曝光） | 会话接口（Create / Update a max delivery or creative boost session） |
| 排期 | `schedule_type` / 起止时间 |

现有插件的动作类型却是 `roi_unlock`、`conversion_repair`、`profit_protection`、`product_expansion` 等内部抽象。用户不知道这些对应 TikTok 后台的哪个按钮，也不知道系统到底改了什么。

### 1.3 官方最有用的数据和规则没用上

| 官方能力 | 现有插件 | 影响 |
|---|---|---|
| 报表支持按小时（`stat_time_hour`），推广系列、商品两级都支持 【官方】 | 只拉按天数据（代码中没有出现 `stat_time_hour`） | 做不到「随时优化」：当天花不出去、或者花太快，都要到第二天才知道 |
| 素材投放状态 `creative_delivery_status` 共 9 种：排队、学习中、投放中、不投放、需授权、已排除、不可用、被拒、不活跃 【官方】 | 只读取了状态，没有做诊断（`NOT_DELIVERYING`、`AUTHORIZATION_NEEDED`、`NOT_ACTIVE` 都没被使用） | 没法告诉用户「有 12 条视频没授权，卡住了投放」 |
| ROI 保障（ROI protection）：达到条件 TikTok 会退广告金 【官方】 | 完全没有考虑 | 系统建议「当天调高 ROI」会让当天的赔付资格作废，等于白白丢钱 |
| `net_cost`（扣除广告金 / 优惠券后的真实花费） 【官方】 | 没用 | 利润算不准 |
| Creative Boost 会话 【官方】 | 没用 | 素材起量少了一个官方手段 |
| 商品级、素材级花费最长有 11 小时延迟；商品级、素材级订单包含自然流量 【官方】 | 没区分 | 用商品 / 素材当天 ROI 做判断会误判 |

### 1.4 门槛太高

「利润与成本」要求每个商品补齐采购、头程、尾程、仓储、佣金、退货率后才放开建议。很多用户卡在这一步，看到的是一堆「成本不完整，已阻断」，插件等于不能用。

## 二、官方规则清单（新引擎的依据）

### 2.1 目标 ROI 与预算

| 规则 | 来源 |
|---|---|
| 目标 ROI 相当于成本上限：预算只是天花板，ROI 目标决定能花到多少。**预算花不出去，通常是 ROI 设得太高，不是投放出了故障** | 【官方】TikTok 指南，经第三方转述 |
| 每次调整 ROI 后至少保持 **3 个完整天** 再评估 | 【官方】 |
| 花得慢：小幅调低 ROI；花得快且 ROI 达标：提高预算，或在 ROI 高于目标时调高 ROI | 【官方】LIVE GMV Max 最佳实践，Product 同理 |
| 预算使用率 **超过 90%**：预算可能太低，加预算可以在保持 ROI 的同时拿更多 GMV | 【官方】 |
| 加预算 **每天最多加 30%**，不要一次大幅加；加完后 ROI 短期回落是正常现象 | 【官方】Max Delivery 最佳实践 |
| 新店 / 新品：先用 Max Delivery 跑 **3–5 天**，日预算 **至少 10 × 客单价**；ROI 达标后可加预算或切回 Target ROI | 【官方】 |
| 大促：Max Delivery 预算设为 Target ROI 模式实际花费的 **1–5 倍**（SPU 维度），**超过 5 倍 ROI 可能大幅下降** | 【官方】 |
| Target ROI 是常态的长期策略；Max Delivery 只用于短期冲量（新品、清库存、大促） | 【官方】 |
| 推荐的起始 ROI 约等于历史非直播 GMV ÷ 历史广告花费；推荐预算约等于 2 × 历史非直播 GMV ÷ 目标 ROI | 【经验】多份第三方指南引用 TikTok 说法 |
| 不要以低于盈亏平衡 ROI（= 1 ÷ 投放前毛利率）的值作为目标 | 【经验】基础财务公式 |
| 用 7 天滚动平均判断，不用昨天单日数据；避免剧烈改动 | 【经验】 |
| Product GMV Max 至少跑 2 周，让更多视频通过学习期；需要放量时，ROI 每次下调 10–30% | 【官方】TikTok Shop 商家大学（新加坡站）课程 |

### 2.2 ROI 保障（广告金赔付） 【官方】

- **触发条件**（两条同时满足）：当天 ROI 低于当天目标 ROI 的 90%，且当天订单 **超过 20 单**。
- **赔付金额** = 当天花费 − 当天 GMV ÷（当天目标 ROI × 0.9）。
- **当天失去赔付资格的情况（Product GMV Max）**：
  - 手动 **调高** 目标 ROI（哪怕一次）
  - 当天手动 **调低** 目标 ROI **超过 1 次**
  - 暂停或删除推广系列
  - 编辑推广系列里的商品
  - 余额不足等原因导致停投
- **不在赔付范围内**：Max Delivery 的花费、Creative Boost 的预算。
- 历史记录只保留 60 天，按广告账户时区统计。

> 由此得出新引擎的硬规则：**白天绝不调高 ROI；每天最多调低一次；需要调高 ROI 或改商品时，放到当天第一件事做，并提示「今天将失去 ROI 保障」。**

### 2.3 素材 【官方】

- 系统会先把所有合格素材放进测试，再把预算逐步集中到信号更好的素材。
- 判断素材供给要看三个数：**可用素材数、已探索比例、优秀素材比例**。
- 9 种投放状态，以及每种该怎么处理：

| 状态 | 含义 | 该怎么做 |
|---|---|---|
| `IN_QUEUE` 排队中 | 等待测试 | 正常，不用管；排队太多说明预算或 ROI 限制了测试 |
| `LEARNING` 学习中 | 正在测试 | 别动它 |
| `DELIVERING` 投放中 | 正常放量 | 优秀素材拿去做同款变体 |
| `NOT_DELIVERYING` 不投放 | 测试后没表现出转化潜力 | 不必删，补新素材 |
| `AUTHORIZATION_NEEDED` 需授权 | 视频没授权给广告用 | **立刻授权**，授权后约 20 分钟生效 |
| `EXCLUDED` 已排除 | 被手动移除 | 确认是否误删，可随时加回 |
| `UNAVAILABLE` 不可用 | 私密、删除或账号封禁；**被拒的视频可能还在花钱** | 检查花费，替换 |
| `REJECTED` 被拒 | 审核未通过 | 申诉或替换 |
| `NOT_ACTIVE` 不活跃 | 上传超过 30 天且 30 天内没有 GMV | 补新素材 |

- 供给基准：Product GMV Max **至少 40 条在投短视频**（商家大学课程）；LIVE GMV Max **每次 50–70 条，或每天新增 5–10 条**。
- 提升质量的方向：更强的开头钩子、更早展示商品价值、更好的节奏、更强的优惠和行动号召、在爆款基础上做变体。
- 官方加速手段：「新视频加速测试」（Accelerate testing）、Creative Boost、开启达人授权视频。

### 2.4 可用数据 【官方，`/gmv_max/report/get/`】

| 层级 | 维度 | 关键指标 |
|---|---|---|
| 账户 | `advertiser_id` + `stat_time_day` / `stat_time_hour` | cost、net_cost、gross_revenue、roi、orders、cost_per_order |
| 推广系列 | `campaign_id` + 天 / 小时 | 以上全部，外加 `roas_bid`（当时的目标 ROI） |
| 商品（SPU） | `item_group_id`（+ 推广系列）+ 天 / 小时 | cost（**最长延迟 11 小时**）、orders、gross_revenue（**含自然流量**）、product_status |
| 素材 | `item_id` | `creative_delivery_status`、cost（延迟最长 11 小时）、orders、gross_revenue（含自然流量）、商品点击率、广告点击率、转化率、2 秒 / 6 秒 / 25% / 50% / 75% / 100% 完播率 |
| 时段（duration） | 推广系列下的时段 | cost、gross_revenue、roi、`roas_bid`、`bid_type` |

> 结论：**推广系列级按小时数据最可靠，用来做「随时」的节奏监控**；商品和素材级数据延迟大、又混入自然流量，只用来做每天一次的判断。

### 2.5 MCP 接入

- 官方 MCP 服务地址：`https://business-api.tiktok.com/open_mcp/tt-ads-mcp-flat`，约 400 个工具，覆盖 GMV Max 推广系列、报表和店铺商品，**不提供店铺订单数据**。
- GMV Max 相关接口：推广系列的查询 / 创建 / 更新、推荐 ROI 与预算、Max Delivery 与 Creative Boost 会话的增删改查、店铺列表与商品、身份与视频、移除 / 加回素材、店铺独占授权、报表。
- 现有插件已经接入了其中大部分工具（`gmv_max_report_get`、`campaign_gmv_max_update`、`gmv_max_bid_recommend_get`、`gmv_max_creative_update`、会话接口等），**V2 不需要换数据源，主要是换判断逻辑和界面**。

## 三、新策略：「一个盈亏线 + 七种诊断 + 每天三个时间点」

### 3.1 只算三条线

每个推广系列都画在同一把尺子上：

```
  ROI ─┼──────────┼──────────────┼──────────────┼────▶
       0     盈亏平衡 ROI    目标 ROI（你设的）  实际 ROI（7 天滚动）
            = 1 ÷ 毛利率       ≥ 盈亏平衡 × 1.15
```

- **毛利率只要一个数**：店铺默认毛利率（必填，30 秒填完），单个商品可选覆盖。**不再因为成本不完整而阻断建议**，只在界面上标注「按店铺默认毛利率估算」。
- **每天赚了多少** = GMV × 毛利率 − 真实花费（`net_cost`）+ ROI 保障赔付的广告金。

### 3.2 七种诊断（每个推广系列只给一个结论、一个动作）

判断统一用 **7 天滚动数据**；学习期、观察期内的系列只显示倒计时。按下表 **从上往下取第一个命中的**：

| # | 诊断（用户看到的话） | 判断条件 | 唯一推荐动作 | 依据 |
|---|---|---|---|---|
| 0 | 🔵 **学习中，先别动** | 新系列不满 3 天，或上次改 ROI / 预算不满 3 天 | 不动；显示「还剩 N 天，第 X 天再看」 | 【官方】ROI 至少保持 3 天 |
| 1 | ⚫ **被卡住了** | 不在投放、余额不足、商品不可用、店铺未授权、在投素材为 0 | 按原因跳到对应修复（充值 / 授权 / 上架） | 【官方】 |
| 2 | 🔴 **在亏钱** | 实际 ROI < 盈亏平衡 ROI，且样本足以下结论（7 天花费 ≥ 5 倍客单价，或订单 ≥ 10）【经验】 | 明早第一件事：调高目标 ROI 到「盈亏平衡 × 1.15」；若当天符合 ROI 保障条件（订单 > 20 且 ROI < 目标的 90%），提示「今天会有广告金赔付，先别动」 | 【官方】ROI 保障规则 |
| 3 | 🟠 **花不出去** | 预算使用率 < 50% 且实际 ROI ≥ 目标 ROI | 调低目标 ROI 10%（每天最多一次，且不低于盈亏平衡 × 1.05） | 【官方】预算花不出去通常是 ROI 太高 |
| 4 | 🟢 **能放量** | 预算使用率 ≥ 80–90% 且实际 ROI ≥ 目标 ROI | 加预算 30%（每天最多一次） | 【官方】使用率 > 90% 加预算，每天最多 +30% |
| 5 | 🟣 **素材不够** | 在投素材 < 40 条，或探索比例低，或有需授权 / 被拒素材 | 授权卡住的素材；开新视频加速测试；交给 AI 制片人补素材 | 【官方】素材供给 |
| 6 | ⚪ **健康，保持** | 以上都不是 | 不动；展示「今天预计赚 ¥X」 | — |

每条诊断都有一张「为什么 / 怎么做 / 做完会怎样」的教学卡，直接引用上面的官方规则。用户照着做，几次之后就会了。

### 3.3 每天三个时间点（「随时优化」但不乱动）

| 时间（账户时区） | 系统做什么 | 允许的动作 |
|---|---|---|
| **早上 9:00 · 定方向** | 用到昨天为止的完整日数据，对所有系列跑一遍七种诊断，生成「今日必做」（最多 5 项） | 调高 ROI（只在早上做，并提示当天失去 ROI 保障）、改商品、加预算 |
| **白天每小时 · 看节奏** | 拉推广系列级的小时数据，和过去 7 天同一时段的累计花费对比 | 只做两件事：① 到下午 2 点花费已超过日预算 70% 且 ROI 达标 → 提醒加预算（+30%）；② 到下午 6 点花费不足同时段基准的 40% → 提醒调低 ROI 10%（当天第一次调低才允许）。**白天永远不建议调高 ROI** |
| **晚上 8:00 · 补素材** | 拉素材状态，汇总卡住的素材和缺口 | 一键授权；把表现最好的素材交给 AI 制片人做变体；给潜力素材开 Creative Boost（提示 Creative Boost 的花费不在 ROI 保障范围内） |

### 3.4 三档自动化（用户自己选）

| 档位 | 行为 | 安全护栏（三档都生效） |
|---|---|---|
| **只提醒**（默认） | 出清单和教学卡，用户去 TikTok 后台自己改 | — |
| **一键执行** | 每张卡片上有「执行」按钮，系统通过 MCP 写入，写完自动进入 3 天观察 | 单次预算变化 ≤ 30%，ROI 每天最多调低一次、每次 ≤ 10% |
| **自动驾驶** | 七种诊断里的 3、4 号（花不出去、能放量）自动执行；2 号（亏钱）和改商品仍需人点头 | 目标 ROI 不低于盈亏平衡 × 1.05；每日总花费上限；白天不调高 ROI；3 天冷却；全部可一键回退 |

### 3.5 做完要看到结果（复盘闭环）

每个执行过的动作 3 天后自动生成复盘：「调高预算 30% → 3 天 GMV +¥4,200，ROI 从 3.4 降到 3.1（仍高于目标 2.9），多赚约 ¥680」。累计显示「本月按建议操作多赚 ¥X」。这是让用户愿意每天打开插件的核心。

## 四、新界面：从 10 页减到 4 页

### 4.1 今日（打开就看）

```
┌ 账户健康：🔴 1 亏钱  🟠 2 花不出去  🟢 1 能放量  🟣 素材缺口 18 条 ─────────────┐
├ 钱：近 7 天利润 ¥12,430 · 今日花费 ¥1,820 / 预算 ¥3,000（比平时快 12%）· ROI 保障待赔 ¥96 ┤
├ 今日必做（按赚钱多少排序，最多 5 项）                                          ┤
│  1. 🔴「耳环-主推」在亏钱：目标 ROI 2.4 → 3.0          [为什么] [执行] [我自己改了] │
│  2. 🟢「项链系列」能放量：预算 ¥800 → ¥1,040            [为什么] [执行]            │
│  3. 🟣 12 条视频需要授权，卡住了投放                     [去授权]                   │
├ 观察中：「手链系列」调低 ROI 后第 2/3 天 · 目前 GMV +18%                         ┤
└ 今天学一招：为什么白天不要调高 ROI？（ROI 保障规则）                              ┘
```

### 4.2 推广系列

- 一张表：系列 · 诊断灯 · 实际 ROI（7 日）· 目标 ROI · 盈亏平衡 ROI · 预算使用率 · 7 日利润 · 学习倒计时 · ROI 保障状态。
- 点开一行：今日按小时的累计花费曲线（和 7 天同时段基准对比）、ROI 三线图、改动历史和复盘结果、可执行动作。

### 4.3 素材

- **供给漏斗**：可用 → 排队 → 学习 → 投放 → 优秀，与官方基准（在投 ≥ 40 条）对比。
- **卡住的素材**：需授权、被拒、不可用（标出仍在花钱的）、误排除，每条一个处理按钮。
- **爆款素材**：一键「交给 AI 制片人做 10 条变体」（调用 V6 的复刻 / 创意工作室配方），产出审核通过后自动发布并授权给 GMV Max。广告插件和内容生产在这里接起来。

### 4.4 设置与学院

- **设置**：店铺默认毛利率、商品毛利率覆盖、自动化档位、安全护栏、通知时间。
- **学院**：把第二章的官方规则做成 10 个短课（每个 1 分钟），诊断卡里的「为什么」链接到对应课程。
- **操作记录**：所有执行和回退的审计记录。

> 现有的 S1–S7、SOP 周期、AI Coach、实验引擎、审批流、10 个页面都不再出现在主界面。可复用的部分（同步、利润计算、执行、审计、回退）保留在后台，AI 只负责把诊断写成人话、生成每日总结，不参与是否动手的判断。

## 五、和系统其他部分打通

| 打通点 | 做法 |
|---|---|

## 七、需要你确认的事

1. **默认毛利率**：用店铺默认毛利率起步、成本不完整也照常给建议（只标注「估算」），可以接受吗？
2. **自动驾驶的边界**：自动执行是否只限「花不出去 → 调低 ROI」和「能放量 → 加预算」两类？
3. **阈值**：在投素材 40 条、加预算 30%、调低 ROI 10%、盈亏平衡 × 1.15 作为目标，这几个默认值是否合适？是否需要按类目区分？
4. **旧版页面**：G2 上线后保留「高级（旧版）」入口多久再删除？
5. **LIVE GMV Max**：本期是否只做 Product GMV Max，直播放到下一期？（直播有自己的规则：至少 3 天、单场 3 小时以上、每次 50–70 条视频等）

**G1 诊断引擎**
- `src/main/modules/tiktok-gmv-max/diagnosis.ts`：七种诊断规则、三条 ROI 线、ROI 保障赔付估算（按官方公式）、学习期倒计时、今日必做排序（被卡住、亏钱优先，其余按每天影响金额排序）、账户汇总。纯函数，单元测试 `npm run test:gmv-max-diagnosis`。
- `src/main/modules/tiktok-gmv-max/v2Workspace.ts`：从本地已同步的数据组装诊断；店铺默认毛利率（缺少商品成本时也能给建议，标注「估算」）；「我已改好」改动记录（触发 3 天学习期）；规则阈值可调。
- 日报表新增拉取官方字段 `net_cost`（扣除广告金后的真实花费）和 `roas_bid`（当天的目标 ROI）。在 TikTok 后台手动改的 ROI 也能识别为学习期。账户不支持这两个字段时，会自动退回原来的字段，不影响同步。
