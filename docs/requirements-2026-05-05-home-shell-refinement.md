# 2026-05-05 首页与壳层精修

## 目标

- 继续按 `DESIGN.md` 精修首页与全局壳层。
- 重点修正顶部控制区、左侧品牌/底部状态区，以及首页中部任务卡与流程卡比例。

## 本次调整

### 顶栏

- 顶栏从“整条横带”继续收紧为分组式工作台结构。
- 搜索框改为独立主输入区，并补充快捷键提示。
- 新增 GPU / API 状态芯片，突出 AI Production Console 工作台感。
- 用户区改为头像 + 名称 + Pro 标记，通知按钮补数量徽标。

### 左侧菜单与底部区域

- 品牌区缩紧尺寸与字重，更接近设计稿头部比例。
- 菜单项高度、圆角、字重整体下调，减轻“按钮感”。
- 底部新增企业版卡片，和系统状态、设置、账号区形成更清晰的层级。
- 设置入口进一步变轻，避免视觉过重。

### 首页中部

- Hero 区收紧排版，优化标题字重、正文宽度和卡片留白。
- KPI 卡片、任务面板、流程面板统一间距和圆角。
- 空任务态改为垂直居中的结构化空状态，增加图标、标题与主按钮。
- 右侧快捷创建卡片压缩高度，整体更接近高密度工作台。
