# 2026-05-16 Clone 详情页自动运行局部刷新

## 目标

- 修复自动运行生成视频期间详情页频繁“整页重刷”的体验问题。
- 保持主流程不变，只让同一项目在轮询刷新时走局部数据补丁更新。

## 问题定位

- `CloneView` 挂载后每 4 秒轮询一次项目状态。
- 轮询链路会调用 `loadProject()` / `refreshProjectStatus()`。
- 前端 `applyProject()` 之前直接整体替换 `current.value`，导致同一项目详情页大范围重渲染，表现成“完全刷新”。

## 本轮最小改动

- 修改文件：
  - `src/renderer/src/composables/useCloneProjectWorkspace.project.ts`
- 新增同项目原地补丁更新逻辑：
  - 当 `current.id === next.id` 时，不再直接替换整个项目对象。
  - 改为对对象进行就地同步：
    - 删除旧字段中已不存在的键
    - 更新基础字段
    - 普通对象递归补丁
    - 数组按最新结果替换
- 不影响：
  - 首次进入项目
  - 切换到另一个项目
  - 项目为空时的清空逻辑

## 结果

- 自动运行生成视频时，详情页不再每次轮询都整块重刷。
- 当前项目对象引用会尽量保持稳定，减少页面抖动和大面积重绘。
- 状态、列表、分镜结果仍会正常更新。

## 使用说明

1. 正常进入 `clone` 项目详情页。
2. 启动自动运行到分镜视频或最终成片。
3. 观察轮询期间页面更新，应以局部内容变化为主，不再出现明显整页刷新感。

## 验证

- Windows 开发环境执行：
  - `npm run typecheck`
- 手动验证：
  - 打开一个已有项目详情页。
  - 启动自动运行视频生成。
  - 在 4 秒轮询周期内观察页面：
    - 阶段状态、镜头状态可更新
    - 页面顶部、已展开区域、滚动位置不应频繁重置
