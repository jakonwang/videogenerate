# 全局样式升级为 AI Production Console 说明

## 摘要

本次按照最新 `DESIGN.md` 与首页设计稿，将全局基础样式层统一升级为 VideoGen 的 AI Production Console 风格。

目标不是先改单个业务页逻辑，而是先把全站基础观感拉回统一基线。

## 修改范围

- `src/renderer/src/styles.css`

## 本次统一内容

### 1. 全局主题 Token

统一到新的深色科技工作台语义：

- `--bg-root`
- `--bg-shell`
- `--bg-panel`
- `--bg-card`
- `--bg-input`
- `--primary`
- `--ai-blue`
- `--ai-purple`
- `--text-main`
- `--text-secondary`
- `--text-muted`
- `--border-base`

### 2. 主框架

统一以下全局骨架：

- 侧栏宽度：`240px`
- 顶栏高度：`72px`
- 页面内边距：`24px`
- 主工作区为深色渐变背景
- 侧栏与顶栏采用半透明面板质感

### 3. 核心基础控件

统一以下基础元素：

- 顶栏搜索框
- 顶栏操作按钮
- 侧栏导航项
- 侧栏底部按钮
- 用户卡片
- 全局按钮
- 全局卡片
- 全局输入框
- 全局滚动条

### 4. 视觉目标

统一后的基础层要优先体现：

- 这是 AI 视频生产控制台
- 不是普通后台管理系统
- 深色、高级、克制、有自动化感

## 不包含内容

本次不包含：

- 单个业务页完整结构改版
- 后端业务链路改动
- `/clone` 状态机改动
- 模型透传逻辑改动

## 后续建议

在全局基础样式统一后，再逐页按新的 `DESIGN.md` 重做：

1. 首页 Dashboard
2. `/clone`
3. 设置中心
4. 模板库 / 任务中心 / 模特库
