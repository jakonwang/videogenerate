# /clone 运行反馈与失败重试

## 摘要

本次补强 `/clone` 生成分镜视频时的前端反馈能力，解决云端生成失败后界面没有明显反应、日志内容溢出、用户无法快速重新生成的问题。

## 功能要求

- 右侧固定信息区新增实时日志流，展示最近运行事件、云端调用上下文和错误信息。
- 日志区域必须限制高度并内部滚动，长错误、HTML 响应片段、接口上下文必须自动换行，不允许撑爆页面布局。
- 云端平台生成失败时，界面必须出现醒目的“生成失败”卡片，并提示用户检查错误上下文后重新生成。
- 分镜视频失败后支持一键“重新生成分镜视频”，单个分镜失败时支持“重新生成该分镜”。
- 前端捕获生成异常后必须主动刷新当前项目状态，确保后端写入的 `lastError`、`pipelineStatus.errorContext` 和分镜失败状态能立即回显。

## 使用说明

1. 在 `/clone` 完成分镜拼图后点击“生成分镜视频”。
2. 如果云端返回错误，右侧“运行反馈”会显示失败卡片和实时日志。
3. 优先查看右侧调用上下文中的 `provider / model / Base URL / 请求能力 / 响应片段`。
4. 修正配置或确认外链可访问后，点击“重新生成分镜视频”。
5. 如果只有某个分镜失败，可在分镜视频卡片或合成前检查卡片中点击“重新生成该分镜”。

## 技术约束

- 仅在渲染进程维护 UI 运行日志，不把日志写入主进程业务数据，保持前后端低耦合。
- 单镜重试复用现有 `clone.generateShotClip` IPC，不新增主进程接口。
- 批量重试复用现有 `clone.generateShotVideosFromStoryboard` IPC，不改变后端生成策略。
