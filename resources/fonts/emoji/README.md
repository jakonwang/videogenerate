常用表情的 SVG 图片，批量字幕渲染成片时用（离线可用，不用联网下载）。

文件名是表情的 Unicode 码点（小写十六进制，多个用 - 连接，不含 fe0f）。不在这里的表情会在渲染时从 jsDelivr 下载并缓存。
